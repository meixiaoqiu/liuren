# Liuren 创建按钮辅助工具

这是一个可选 Chrome 扩展，仅用于本地开发和冒烟测试。它会反复查找 Filament 渲染的 `Create` 按钮，并在随机延迟后点击。

不要在生产域名或不受你控制的网站上安装和使用它。

## 默认作用范围

扩展默认只匹配：

- `http://localhost/*`
- `http://127.0.0.1/*`

如果你的本地开发域名不同，可以在本地修改 `manifest.json`。不要提交私人主机名、真实生产域名或服务器地址。

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 启用“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择当前 `tools/chrome` 目录。

## 行为

- 查找 Filament 渲染的 `Create` 按钮。
- 按钮可见且可用时点击它。
- 在随机延迟后重复尝试。
- 在浏览器控制台输出开发调试信息。
