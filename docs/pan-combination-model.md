# 起盘排列组合定义

## “排列组合”的含义

本项目所说的起盘“排列组合”，特指 **月将加时** 形成的相对位置，也就是月将落在时支上的“指针”。

它不是数据库中的独立字段。在当前实现中，这个指针由 `tianpan0` 表示：

```text
月将加时指针 = (月将 - 时支) mod 12
```

`tianpan0` 确定后，`tianpan1` 至 `tianpan11` 按十二地支依次循环排列。因此，月将加时指针只可能是 `0` 至 `11`，总共 **12 种排列组合**。

## 不参与排列组合统计的字段

以下八个四柱字段不参与排列组合统计：

- `niangan`：年干
- `nianzhi`：年支
- `yuegan`：月干
- `yuezhi`：月支
- `rigan`：日干
- `rizhi`：日支
- `shigan`：时干
- `shizhi`：时支

月将和时支也不是两个独立的统计维度；它们只共同决定月将加时的相对指针。

日干支等数据会影响四课、三传、九宗门及其他后续计算结果，但这些变化不增加“月将加时排列”的种类。不要把完整起盘结果的差异数量当成月将加时排列组合的数量。

## 720核心课回归测试口径

完整的归一化盘面不能只按12种月将加时指针保护。四课、三传等结果还受六十日柱影响，因此核心回归状态为：

```text
12种月将加时指针 × 60种日柱 = 720课
```

日柱在这里用于确定测试状态，但八个四柱字段本身不进入快照比较。输入时间、四柱编码和原始月将值也不进入归一化盘面比较：

- `shichen`
- `sizhu`
- `yuejiang`
- `niangan`、`nianzhi`
- `yuegan`、`yuezhi`
- `rigan`、`rizhi`
- `shigan`、`shizhi`

每课使用精确课号标识，课号不带昼夜后缀，例如：

```text
pointer-03_day-17
```

## 天将独立测试口径

十二天将（`tianjiang0` 至 `tianjiang11`）和三传天将（`sanchuan0tianjiang` 至 `sanchuan2tianjiang`）共15个字段是依赖占时的动态变量，不进入核心基线。它们由独立的 `PanNoblemanTest` 保护，覆盖：

- 十干的昼贵与夜贵；
- 北京固定 UTC+8 的日出日落切换（边界前一秒、当秒及后一秒）；
- 贵人落十二地盘宫的顺逆布将；
- 完整十二天将排列及三传所乘天将。

天将测试使用独立的固定规则表或明确的预期值，不调用待测昼夜算法生成预期值。

## 回归测试保证

1. 720个核心课号完整且没有重复；
2. 每课的所有归一化盘面字段与已批准基线逐字段一致；
3. 测试失败时报告发生变化的课号和字段；
4. 更新基线只能明确指定一个或多个精确课号，不能整体覆盖；
5. 未明确批准的任何课都必须保持不变。
