# 起盘排列组合定义

## “排列组合”的含义

本项目所说的起盘“排列组合”，特指 **月将加时** 形成的相对位置，也就是月将落在时支上的“指针”。

它不是数据库中的独立字段。在当前实现中，这个指针由 `tianpan0` 表示：

```text
月将加时指针 = (月将 - 时支) mod 12
```

`tianpan0` 确定后，`tianpan1` 至 `tianpan11` 按十二地支依次循环排列。因此，月将加时指针只可能是 `0` 至 `11`，总共 **12 种排列组合**。

## 不参与排列组合统计的字段

以下八个四柱字段不参与排列组合统计：

- `niangan`：年干
- `nianzhi`：年支
- `yuegan`：月干
- `yuezhi`：月支
- `rigan`：日干
- `rizhi`：日支
- `shigan`：时干
- `shizhi`：时支

月将和时支也不是两个独立的统计维度；它们只共同决定月将加时的相对指针。

日干支等数据会影响四课、三传、九宗门及其他后续计算结果，但这些变化不增加“月将加时排列”的种类。不要把完整起盘结果的差异数量当成月将加时排列组合的数量。

## 1440课回归测试口径

完整的归一化盘面不能只按12种月将加时指针保护。四课、三传等结果还受六十日柱影响，天将及三传天将还受昼贵、夜贵影响。因此完整回归状态为：

```text
12种月将加时指针 × 60种日柱 × 2种昼夜贵人 = 1440课
```

日柱在这里用于确定测试状态，但八个四柱字段本身不进入快照比较。输入时间、四柱编码和原始月将值也不进入归一化盘面比较：

- `shichen`
- `sizhu`
- `yuejiang`
- `niangan`、`nianzhi`
- `yuegan`、`yuezhi`
- `rigan`、`rizhi`
- `shigan`、`shizhi`

每课使用精确课号标识，例如：

```text
pointer-03_day-17_night
```

回归测试必须保证：

1. 1440个课号完整且没有重复；
2. 每课的所有归一化盘面字段与已批准基线逐字段一致；
3. 测试失败时报告发生变化的课号和字段；
4. 更新基线只能明确指定一个或多个精确课号，不能整体覆盖；
5. 未明确批准的任何课都必须保持不变。
