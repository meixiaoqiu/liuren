# 第一法 · 前后引从升迁吉

## 一、体系归属

- 出处：《六壬大全·毕法赋》第一法。
- 判读对象：当前盘面（必要时配合占者本命 / 行年）。
- 程序归属：毕法独立规则类的实现文件位于 `app/Domain/Pan/BiFa/Rules/`，第一法对应"前后引从升迁吉"，注册于 `BiFaRuleRegistry`。
- 与课经第 22 课"引从课"的关系：在结构上存在大量重合（拱天干 / 拱地支 / 干支夹拱禄贵等），但毕法与课经是两份独立的典籍与判读逻辑：
  - 课经第 22 课以"成课"为单位判定，命中即整课出现，并承担组课排盘逻辑；
  - 毕法第一法以"分格"为单位判定，一张盘可同时命中若干分格；
  - 毕法第一法不复用课经"引从课"的 matcher，分格定义、断义与课经各自独立维护；
  - 案例独立登记于 `BiFaCaseCatalog`，即使与课经共享同一古籍盘（例如庚辰日），也以独立 case_id 区分。
- 毕法体系不与 `RuleRegistry` 共用注册路径；排盘页"解盘信息"（课经）与"毕法"是两块独立 UI。

## 二、古籍原文

> 第一法 · 前后引从升迁吉。
>
> 凡课日辰前后上神发用为初末传者，前为引，后为从。前引后从，主迁官进职、修宅迁居。此格有五等。
>
> 一曰引从天干。初传居干前为引，末传居干后为从，前后夹拱日干寄宫，主进职迁官。
>
> 二曰初末引从地支。初传居日前为引，末传居日后为从，前后夹拱地支，主迁修家宅。
>
> 三曰拱贵。引从天干成立，干上神恰乘昼夜贵人之一，主以贵人引荐，成事最吉。
>
> 四曰两贵引从天干。引从天干成立，初末传恰为昼夜二贵，贵人身份可互换，初末方向不可互换。
>
> 五曰干支夹拱年命。昼夜贵人分临干支，干支前后夹拱年命，主得两贵成就。
>
> 又曰伏吟干支拱日禄，宜占食禄。伏吟干支拱昼夜贵，宜告贵求禄。若干支并初中及中末拱地贵，告贵谋事亦吉。
>
> 庚辰日干上丑昼贵，初传寅加酉居日前、末传子加未居日后，为拱天干，又为拱贵。壬子日初传巳、末传卯，拱天干且初末恰为昼夜二贵，为两贵引从。甲午日初传子居支前、末传戌居支后，为拱地支。丁酉日酉为夜贵加丁干、亥为昼贵加日支，年命在申，为贵临支干拱年命。丁巳、己巳、癸亥日伏吟，为干支拱日禄。庚午、己酉日伏吟拱夜贵。甲子日伏吟拱昼贵。

> 象曰：拱夹支干，仕人佳兆，官职升迁，名利荣耀，孕生英儿，婚招金玉，出行取财，干贵欢笑。

## 三、原文分格

- 分格 1：初末引从天干（"拱天干"）。初传居干前、末传居干后。
- 分格 2：初末引从地支（"拱地支"）。初传居日前、末传居日后。
- 分格 3：拱贵。引从天干 + 干上神为昼夜贵之一。
- 分格 4：两贵引从天干格。引从天干 + 初末传恰为昼夜二贵。
- 分格 5：贵临干支拱年命。昼夜贵人分临干支 + 干支前后夹拱年命（可取本命或行年）。
- 分格 6：二贵拱年命。初末传恰为昼夜二贵 + 初末前后夹拱年命（可取本命或行年）。
- 分格 7：伏吟 · 干支拱日禄（丁巳、己巳、癸亥日伏吟）。
- 分格 8：伏吟 · 干支拱昼夜贵（庚午、己酉日伏吟拱夜贵；甲子日伏吟拱昼贵）。
- 分格 9：干支并初中拱地盘贵人（"若干支并初中及中末拱地贵"）。

## 四、现代汉语解释

第一法以"前后引从"为核心意象：初传位于某目标前一宫、末传位于同一目标后一宫。

- "前"指十二支顺时针下一宫（数值 +1 mod 12）；"后"指逆时针上一宫（数值 -1 ≡ +11 mod 12）。
- "目标"可以是日干寄宫、日支、昼夜贵人、日禄、本命（行年）。
- 引从天干 / 引从地支 必须"初在前、末在后"——前后方向不可互换；颠倒则"引从"语义不成立。
- 拱年命 / 拱禄贵 / 初中与干支共同拱贵 等"夹拱"结构，目标在前一宫或后一宫均可，前后不区分。
- 一张盘可以同时命中以下若干分格；命中其一即第一法整体成立；具体断义按命中的分格而定。

## 五、程序语义

第一法共整理为 **9 类古籍分格**，对应 **10 条程序判断 route**——古籍"干支拱昼夜贵"为同一类，程序拆为昼贵与夜贵两条独立 route。

| route code | 中文标题 | 前置条件 |
|---|---|---|
| `yin_gan` | 引从天干 | 初传临日干寄宫前一宫 + 末传临日干寄宫后一宫 |
| `yin_zhi` | 初末引从地支 | 初传临日支前一宫 + 末传临日支后一宫 |
| `gong_gui` | 拱贵格 | `yin_gan` + 日干寄宫之上神 ∈ {昼贵, 夜贵} |
| `liang_gui_yin_gan` | 两贵引从天干格 | `yin_gan` + `{初传, 末传} == {昼贵, 夜贵}` |
| `gui_lin_gan_zhi_gang_nianming` | 贵临干支拱年命 | `{干上, 支上} == {昼贵, 夜贵}` + 干支前后夹拱本命/行年 |
| `er_gui_gang_nianming` | 二贵拱年命 | `{初传, 末传} == {昼贵, 夜贵}` + 初末前后夹拱本命/行年 |
| `gan_zhi_gang_ri_lu` | 干支拱日禄 | 伏吟 + 干支前后夹拱日禄 |
| `gan_zhi_gang_zhou_gui` | 干支拱昼贵 | 伏吟 + 干支前后夹拱昼贵 |
| `gan_zhi_gang_ye_gui` | 干支拱夜贵 | 伏吟 + 干支前后夹拱夜贵 |
| `gan_zhi_bing_chu_zhong_gui` | 干支并初中拱地盘贵人 | 干支夹拱 `target` + 初中夹拱同一 `target`（`target ∈ {昼贵, 夜贵}`） |

辅助判定：

- `flanks(a, b, target)`：无方向夹拱；a、b 两个宫位只要分别位于 target 的前一宫 / 后一宫，前后顺序不区分。用于：
  - 干支拱年命（E）
  - 初末二贵拱年命（F）
  - 干支拱日禄 / 昼夜贵（G、H）
  - 干支与初中共同拱贵（I）
- 方向性比较：引从天干 / 引从地支 用"初传必须居前、末传必须居后"的等值判断，不使用 `flanks()`。

## 六、工程裁决

- 与课经第 22 课"引从课"代码复用方式：
  - 复用：`PanFacts` 提供的天盘反查 helper（`heavenBranchGroundPosition`）、干寄宫（`stemLodgingBranch`）、伏吟判定（`hasPlatePattern`）、命主信息（`personByRole`）。
  - 不复用：课经"引从课"匹配器的匹配结果、课经注册表注册路径、`RuleMatch` 数据结构。
  - 第一法 matcher 与课经"引从课" matcher 在文件层、命名空间层、注册层、UI 层均独立维护。

- 人物资料边界：
  - 引干、引支、拱贵、两贵引干、干支拱昼夜贵、初中拱地盘贵人——7 条 route 完全可独立判定，不需要人物资料。
  - 贵临干支拱年命（E）、二贵拱年命（F）——2 条 route 需要占测者本命 / 行年。
  - 缺人物资料时：其余 8 条 route 正常判断；E / F 标记为"待评估"（不视为命中，也不冒充成立）。
  - nianming 与 xingnian 任一存在即视为可参与 E / F 判定；两者皆缺时才标记为 people_missing。

- 命中证据文案：E / F 命中后，detail 仅显示真正命中的本命 / 行年，不堆砌全部目标。

- 引擎策略：BiFaRuleEngine 在"matched_routes 与 pending_routes 同时为空"时，第一法 BiFaRuleMatch 整体不返回——避免 100 法全未命中时排盘页铺满卡片。

- 文案统一：第一法共 9 类古籍分格、10 条程序 route，不出现"9 个程序分格"等不一致描述。

- 待评估路线：以下两条 route 在缺人物资料时进入 `pending_routes`，前端展示"为"待评估"标记，不计入命中：
  - `gui_lin_gan_zhi_gang_nianming`
  - `er_gui_gang_nianming`

## 八、与课经第 22 课"引从课"的关系

- 课经第 22 课以"成课"为单位，命中即整课出现；
- 毕法第一法以"分格"为单位，一张盘可同时命中若干分格；
- 课经案例与毕法案例的 case_id 命名空间独立（`lesson.*` vs `bifa.*`），同一古籍盘可以同时登记两个独立案例。
