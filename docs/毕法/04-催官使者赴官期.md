# 第四法 · 催官使者赴官期

## 一、体系归属

本法出自《六壬大全·毕法赋》第四法，主体依据是《大全》正文；催官符的解释主要借助《六壬粹言》；冬土局返本煞的「土局与火同」处理依据《御定六壬直指》。本法独立于课经，绝不复用 `App\Domain\Pan\Rules\GuimuRule::DAY_GHOSTS` 课经特殊日鬼表；本法也不调用前三法的任何 matcher；不把占事类型（赴任、就职等）作为 matcher 门槛。本法属于毕法独立区块，由 `BiFaRuleEngine` + `BiFaRuleRegistry` 触发，单独呈现于排盘页「毕法」卡片区。

## 二、古籍原文

> 催官使者赴官期，
>
> 日鬼乘虎末日干，为催官使者。占试有催官之喜。占官赴任必催速。
>
> 催官符，干上官星临支辰年命，更三传递进，或太岁入传。有催官之喜。
>
> 三传递进生旺。
>
> 父母爻，凡占赴任召试，必要日辰三传年命六处见父母爻，旺相有举荐之喜，休囚死绝无益。若父母空亡，须见贵人。德入天门，太岁入传。进士受官赴任，得此卒成。赴任必催。
>
> 庚午日昼贵人在子作父母爻，申乘青龙为用，主赴任极快，乘太岁尤妙。乙卯日昼贵空，不用。
>
> 己日昼贵在子，夜贵在申，为己土长生贵人。占赴任，得此必利到任。己卯日夜贵空，不用。

注：本研究以《六壬大全·毕法赋》通行本为底本；上引「催官符」「父母爻」「长生作贵人」三段皆出自原文片段，仅按本法冻结的研究理解释措辞；「乙卯日昼贵空，不用」「己卯日夜贵空，不用」两句按底本原貌保留，作为特殊负例的明确依据。

## 三、四条正式 matcher（route）

第四法共整理为 4 条正式成立路线，任一成立即第四法成立：

1. **催官使者** → route `cui_guan_messenger`
   - 条件：日鬼或官星乘白虎（天将序号 7），加临日干寄宫、本命或行年。
   - 「官星」按普通五行官鬼表取用（见第五节），不与课经鬼墓课特殊日鬼表混用。
   - 不要求官星发用、不要求官星进入三传、不要求三传结构、不要求赴任占事上下文。

2. **催官符** → route `cui_guan_talisman`
   - 条件：官星加临日干寄宫、本命或行年任一位置；
     且三传组成完整三合局；且三合局五行生官星五行。
   - 释义依据《六壬粹言》：「辛未日午为官星，三传亥卯未成木局，木局整体生午火官星，故为催官符。」——必须按「局生官」整体判定，不按「初、中、末分别生官」分别判定。

3. **恩主举荐·父母爻** → route `patron_parent_line`
   - 条件：父母爻出现在干上神、支上神、初传、中传、末传、本命上神、行年上神任一处。
   - 古书以「年命」合称一处；程序展开为七个物理位置检查。

5. **恩主举荐·长生作贵人** → route `patron_noble_as_growth`
   - 条件：当前所用天乙贵人的天盘地支恰为日干的六壬五行长生支。
   - 典型用例：己日夜贵申，恰为己土长生支。
   - 贵人为当前所用贵人，不是第三法的反取帘幕贵人。

## 四、不作为 matcher 的内容

- **返本煞**：只在第四法已成立后作为减损断义，绝不单独触发第四法。
- **返吟**：第四法已成立后增加「赴任得返吟，多主任期难满或赴任反复」减损断义；不单独触发第四法。
- **催官使者空亡**：减损断义，不阻塞 route 成立。
- **占事类型**（赴任、催科、考试）：用户从未被要求选择占事类型；古籍「赴官期」是断义语境，不是 matcher 门槛。
- **课经特殊日鬼表**：第四法严格按普通五行官鬼表取官星；不复用 `GuimuRule::DAY_GHOSTS`。
- **课经三传旬遁空亡**：仅用通用日旬空（`(xunHead+10)%12` 与 `(xunHead+11)%12`）作减损证据。

## 五、普通五行官鬼表

第四法独立维护 `DAY_OFFICIALS`，不调用 `GuimuRule::DAY_GHOSTS`。程序表如下：

| 甲（0） | 木 | 申（8）、酉（9） |
| 乙（1） | 木 | 申（8）、酉（9） |
| 丙（2） | 火 | 亥（11）、子（0） |
| 丁（3） | 火 | 亥（11）、子（0） |
| 戊（4） | 土 | 寅（2）、卯（3） |

为何不调用课经 `GuimuRule::DAY_GHOSTS`：课经鬼墓课使用《六壬大全·课经》同性单鬼表——甲日专取申、乙日专取酉、丙日专取子、丁日专取亥、戊日专取卯、己日专取寅、庚日专取午、辛日专取巳、壬日专取辰、癸日专取戌——是课经特定格局的鬼墓判定规则，与毕法第四法的「五行普通官鬼」语义不同。本法程序独立维护 `DAY_OFFICIALS`，注释明确写「与课经 `GuimuRule::DAY_GHOSTS` 同性单鬼表不同」，避免误用与未来课经演化时的漂移。

## 六、父母爻表

父母爻按「生日干」的五行为父母：木日父母为水、火日父母为木、土日父母为火、金日父母为土、水日父母为金。具体地支如下：

| 乙（1） | 木 | 亥（11）、子（0） |
| 丙（2） | 火 | 寅（2）、卯（3） |
| 丁（3） | 火 | 寅（2）、卯（3） |

## 七、长生作贵人算法

长生位取自既有 `App\Domain\Pan\Rules\TianyuRule::DAY_ORIGIN`（六壬五行长生位，阴阳干同取，不阴干逆行）。为避免跨体系耦合，本法内部独立维护一份 `DAY_ORIGIN`，但要求与 `TianyuRule::DAY_ORIGIN` 严格一致，原表有变化时此处必须同步。

| 日干 | 长生支 |
| --- | --- |
| 甲（0） | 亥（11） |
| 乙（1） | 亥（11） |
| 丙（2） | 寅（2） |
| 丁（3） | 寅（2） |
| 戊（4） | 申（8） |
| 己（5） | 申（8） |
| 庚（6） | 巳（5） |
| 辛（7） | 巳（5） |
| 壬（8） | 申（8） |
| 癸（9） | 申（8） |

贵人昼夜取法沿用前三法已冻结的贵人表与生产 `guirenPeriod`：昼占取 `DAY_NOBLE[$rigan]`，夜占取 `NIGHT_NOBLE[$rigan]`。当前所用贵人 == 长生支 时 Route 4 成立。

注意：Route 4 检查的是「当前天乙贵人」，不是第三法的「帘幕贵人」（帘幕贵人 = 昼占反取夜贵 / 夜占反取昼贵）。

## 八、乙卯昼贵空、己卯夜贵空的特殊边界

正文明确两条「不用」特例，必须作为 Route 3 / Route 4 的特殊负例保护：

1. **乙卯日**：乙日昼贵为子。若判断恰好完全依靠「昼贵子作父母爻」，且该昼贵子落入甲辰旬空，则**不可**仅凭这条路径成立 Route 3。Route 3 的其它父母爻落点仍可独立成立。
2. **己卯日**：己日夜贵为申，恰为日干长生支。若该夜贵申落入甲申旬空，则 Route 4 整体不成立。Route 3 父母爻仍可由其它落点成立。

正文没有把这两条特例推广为：

- 「所有父母爻旬空都不成立」 — 仅乙卯日 + 昼贵子被禁用；
- 「所有长生贵人旬空都不成立」 — 仅己卯日 + 夜贵申被禁用；
- 「所有贵人空亡都减损或不用」 — 第四法对一般贵人空亡不作减损（第三法的帘幕空墓受克减损不引入第四法）。

程序实现：

- `isYiMaoDayNobleVoided` 检测 乙卯日 + 昼贵子 + 子旬空 三条件同存。
- `isJiMaoOriginVoided` 检测 己卯日 + 夜贵申 + 申旬空 三条件同存。
- `Route 3` 在 yiMao 触发时仅当所有 `parent_hits` 都落在 `DAY_NOBLE[$rigan] = 子` 时屏蔽整条；任意其它父母爻落点保留命中。
- `Route 4` 在 jiMao 触发时无条件不成立。

单元测试明确锁住这两个特例，同时测试普通父母爻旬空没有被一刀切取消。

## 九、催官使者空亡的处理

正文：「使者空亡，则虚信，或被遣差。」

第四法处理：

- `cui_guan_messenger` 已经成立后，使者所乘官星落入本旬空时，**不影响 Route 1 成立**。
- 仅附加一条 reduce 断义：「催官使者空亡 · 力量减损，主虚信、或虽催促而事不实、另有差遣」。

程序绝不能写成：

```text
if 官星空亡 => route=false
```

本法明确在 `messengerIsVoid` 仅写入 evidence、`messengerMatched` 判定不引用该字段。

## 十、四时返本煞（《六壬大全》口径）

正文称「返本煞」按四时返回本季局名。本法严格按《六壬大全》口径：

| 季 | 返本局 |
| --- | --- |
| 春 | 巳酉丑（金局） |
| 夏 | 申子辰（水局） |
| 秋 | 寅午戌（火局） |
| 冬 | 按《御定六壬直指》「土局与火同」处理，按寅午戌（火局）判定 |

季节使用项目已有的真实四时算法：`PanFacts::seasonalPeriod()`，按四立交节与「本季结束前十八日土旺」精确推算（详见第三法研究文档）。

「冬土局」解释：《大全》原文「冬土局」存在但与其他三季体例不对称；《御定六壬直指》明确「土局与火同」，故本法把冬土局按寅午戌火局处理——土受火生，返本煞落于冬时仍按火局断义。

如果三传组成当季返本局（用 `BranchRelations::sanheTriple($initial, $middle, $final)` 严格匹配），且第四法已因 Route 1～4 任一成立，则命中：

- 第四法继续成立（route 不变）；
- evidence 中 `fanben_hit = true`，供排盘页 KnowledgeCard 作为减损断义来源。

### 《六壬大全》与《六壬粹言》返本煞异说

- 《六壬大全·毕法赋》本法主体口径：春金、夏水、秋火、冬土（《御定六壬直指》按寅午戌）。
- 《六壬粹言》另作：春金、夏水、秋木、冬火，与本项目主体依据的《大全》口径不同，属异说。
- 本项目不采用《粹言》异说，仅在本研究文档中如实记录。生产 matcher 只接受《大全》+《御定六壬直指》冬土按寅午戌的口径。

## 十一、返吟只作 judgment

若 `PanFacts::hasPlatePattern('fanyin')` 为真，且第四法已成立，则附加 reduce 断义：

> 返吟附加 · 赴任得返吟，多主任期难满或赴任反复。

返吟绝不单独触发第四法：

```text
if hasPlatePattern('fanyin') && matchedRoutes === [] => return null
```

## 十二、人物资料与 pending 规则

- **Route 1（催官使者）**：日干路径独立。日干已命中直接成立；日干不成立且本命/行年全缺时标记 pending；已有本命或行年则只判断已有字段。
- **Route 2（催官符）**：日干路径优先。日干已命中且三传合局、局生官即成立；日干不成立且本命/行年全缺时标记 pending；本命或行年存在则只判断已有字段。
- **Route 3（父母爻）**：前五处（干上、支上、初传、中传、末传）始终可判；本命/行年提供额外两处候选。本命/行年均缺时仍可由前五处命中；前五处都不命中时仅依赖本命/行年一项不成立。
- **Route 4（长生作贵人）**：完全不依赖人物资料，不存在 pending 状态。

## 十五、未程序化或仅作研究的内容

- 课经特殊日鬼表（`GuimuRule::DAY_GHOSTS`）严格区分，不复用、不参与第四法判定。
- 《六壬粹言》春金、夏水、秋木、冬火的返本煞异说，仅记录，不进入生产 matcher。
- 课经层面诸如「日鬼发用」「日鬼入墓」等的课级判定属于课经体系，不进入第四法。
- 用户占事类型选择（赴任、就职、考试）从未被要求作为 matcher 输入。
- 逐日喜忌的展开式（类似第三法的甲忌未墓、庚忌丑墓）目前没有完整《大全》汇总资料，未程序化。
