# 第十七课：官爵课

## 《六壬大全》原文与课例

“凡课得岁月年命，驿马发用，又天魁太常入传，为官爵课。”驿马是三合局首支之冲神，主驿递、传命；天魁为戌，象印绶，太常亦主官职爵禄。

《大全》标准例为未年二月丁亥日巳时、戌将，癸亥命、行年在午，三传巳、戌、卯。太岁未、月建卯、占日亥及本命亥的驿马均为巳，故驿马发用；戌入中传，三传又见太常，成立官爵课。

## 编程判断

程序按课经正文识别：

1. 分别计算太岁、月建、本命、行年的驿马。
2. 上述至少一项驿马必须发用；驿马只入中传或末传不成立。
3. 天魁戌必须进入三传。
4. 三传所乘天将至少一处为太常；天魁与太常不要求同处一传。
5. 三组条件同时成立，才判官爵课。

标准课例所说“岁月日命，俱马在巳”证明占日驿马属于课内考察信息，但不能证明只有占日驿马发用即可独立成立官爵课。因此程序采用保守口径：占日驿马只记录，不作为成立来源。课经后文所说四马带印绶，又遇德神、天马、青龙、日辰二马，以及日用旺相，均属加吉条件，不作为官爵课的成立门槛。

## 象

官爵印绶，得之荣华。财名吉利，病讼堪嗟。访人不在，行者还家。孕生贵子，仕宦尤佳。
