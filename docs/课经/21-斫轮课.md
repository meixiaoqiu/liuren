# 第二十一课：斫轮课

## 《六壬大全》原文与课例

出处：《六壬大全》卷八《课经集（二）·斫轮课》。底本见 https://www.deeporacle.ai/dianji/liuren-daquan/122-zhuo-lun-ke ，对照本见 https://www.xunqihuang.com/book/chapter/e05f300c4f1caff7.html 。

原文：

“凡课卯加庚或加辛为用，曰斫轮课。卯为车轮，庚辛为刀斧，木就金斫，故名斫轮。占者官禄位高迁，统颐之体，乃革故鼎新之课也。”

象曰：“木欲成器，须假金斫，孕病凶险，财喜欢跃，禄位加增，官职超擢，戌印常绶，遇之犹乐。”

课例：

“如辛丑日辰时亥将，一下克上，卯加申为用，曰斫轮课。”

课例四课（右起）：辛上巳、巳上子、丑上申、申上卯。三传为卯、申、子（初卯乘玄武、中申乘朱雀、末子乘天空）；初传卯即“卯加申”（天盘卯加临地盘申，申属金）。

## 编程判断

程序采用“卯加庚或加辛发用”为成课条件，庚辛按地支金支落位（申为庚、酉为辛）：

1. 初传为卯（太冲，木，车轮）。
2. 天盘卯加临地盘申（庚）或酉（辛）。

精确程序条件：`sanchuan0=3`（初传卯），且 `tianpan[8]=3`（卯加申）或 `tianpan[9]=3`（卯加酉）。

“卯加申”“卯加酉”即四课中有「申上卯」「酉上卯」这一课（上神卯、下神申或酉），其发用为卯；天盘 `tianpan[8]=3`、`tianpan[9]=3` 与四课「申上卯」「酉上卯」是同一事实的两种表述。

《订讹》作“卯加庚辛申酉发用”“卯加庚与申为上，辛酉次之”，与本实现一致——庚对申、辛对酉。

以下不作为课名成立门槛，仅属附加课义：天将、日干、旺相、空亡、月份、日墓等。
