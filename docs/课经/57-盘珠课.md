# 57 盘珠课

## 一、冻结结论

正式 matcher 采用《六壬大全》正文定义：太岁、月建、日支、占时四建与三传，全部出现在四课整体结构的地支集合中，成立盘珠课。

```text
L = 四课整体结构中的地支集合
  = unique(sike[1], sike[2], sike[3], sike[4], sike[5], sike[6], sike[7])

Panzhu =
    nianzhi ∈ L
    AND yuezhi ∈ L
    AND rizhi ∈ L
    AND shizhi ∈ L
    AND sanchuan0 ∈ L
    AND sanchuan1 ∈ L
    AND sanchuan2 ∈ L
```

`sike[0]` 是日干，绝不按同索引地支混入 `L`。

本课另独立实现两个格：

```text
天心格 =
    四建全部在四课地支集合
    OR 四建全部在三传

回还格 =
    三传全部在四课地支集合
```

盘珠课成立时必同时成立天心格正文路线与回还格；但天心格、回还格可以单独成立。

## 二、《六壬大全》正文

可核验来源：

- 中国哲学书电子化计划：《六壬大全》盘珠课：https://ctext.org/wiki.pl?chapter=611073&if=gb&remap=gb
- 识典古籍：《六壬大全·盘珠课》：https://www.shidianguji.com/book/SK1599/chapter/1k1lql3rdidy3

正文主定义：

> 凡太岁、月建及日、时并三传皆在四课之中，曰盘珠课也。

正文随后分别定义：岁月日时皆在四课为天心格，三传皆在四课为回还格，并明确“此二格合一，如盘中走珠，不出于外，故名盘珠”。因此本项目把两个格独立建模，同时把二者合一后的严格正文形态作为盘珠课主体。

卦体：**大壮卦 ䷡**，正文称“凤翔丹山之课”。

《象曰》：

> 三传四课，偶合异常。吉则成福，凶则成殃。贼不出境，行人还乡。阴私解释，事反不良。

## 三、“四课之中”为什么不是只看四个上神

正文天心格例为“甲子年七月乙巳日酉时巳将占，岁月日时皆在四课之上”。按月将巳加酉起课，其四课为：

```text
乙 → 子
子 → 申
巳 → 丑
丑 → 酉
```

四个上神仅为子、申、丑、酉，而四建中的日支“巳”只在第三课下位。若程序只检查 `sike[1,3,5,7]`，正文自己的天心格例就会被排除。

因此“在四课之中”程序化为四课整体结构中的地支位置 `sike[1..7]`，其中 `sike[0]` 为日干，必须排除。第二课、第四课的下位虽与前课上神重复，去重只影响展示，不改变集合成员关系。

## 四、“日”取日支而不是日干

《订讹》把岁、月、日、时合称“四建”，并讨论“四建偶或同宫”从而可能俱在三传。四建均为地支层面的年支、月支、日支、时支，因此正文“日”程序化为 `rizhi`，不取 `rigan`。

## 五、天心格的《订讹》扩展

《订讹》明确：

> 天心：岁月日时俱在四课之上，或俱在三传之中，皆是也。

所以独立 `TianxinRule` 采用两个 OR 路线：

1. 四建全部在四课地支集合；
2. 四建全部在三传。

第二路线不是盘珠课的放宽条件。盘珠主体仍严格采用正文“年月日时、三传皆在四课”的定义。

## 六、回还格独立成立

正文另举“戊子日子时未将占，三传俱在四课之上，为回还格”，并没有称盘珠课。故：

```text
回还格 alone ≠ 盘珠课
```

程序将 `HuihuanRule` 作为 `marker = 格` 的独立规则，不要求盘珠课先成立。正文另有“辛亥日、三传戌酉申”与“戊子日子时未将”两条回还格材料；目录继续保留为 `source_examples`，因为它们属于附格证据而非盘珠主体 `cases`。1900–2100 生产搜索已分别找到可执行复现：辛亥例可用 `1900-02-07 01:00`，戊子例可用 `1900-07-14 00:00`（另有 `1900-07-13 23:00` 晚子时样本）。

## 七、正文盘珠课例与现代生产复现

正文：庚戌年十二丑月，甲子日丑时子将占；四课盘式对应：

```text
甲 → 丑
丑 → 子
子 → 亥
亥 → 戌

四课地支集合：丑、子、亥、戌
三传：子 → 亥 → 戌
四建：戌、丑、子、丑
```

现代生产复现采用：

```text
2031-01-24 01:00
```

该时刻在大寒后、立春前，项目八字节气口径为庚戌年、丑月、甲子日、丑时，生产月将为子。规则应得到：

```text
nianzhi = 戌
 yuezhi = 丑
 rizhi  = 子
 shizhi = 丑
 yuejiang = 子

sike = [甲, 丑, 丑, 子, 子, 亥, 亥, 戌]
三传 = 子、亥、戌
```

因此四建与三传全部包含于四课地支集合 `{丑, 子, 亥, 戌}`，同时命中盘珠课、天心格、回还格。

## 八、成课条件与吉凶判断严格分离

正文在主定义之后继续讨论：

- 日用旺相、神将吉；
- 四课不备；
- 反吟；
- 斩关与中末空；
- 重阴、重阳、阴覆阳、阳覆阴；
- 病讼、生产、忧疑、解释等占类；
- 日用囚死、神将凶。

这些内容均不并入主体 matcher。尤其正文明确“或四课不备，守旧动作亦吉”，所以“四课不备”绝不是盘珠课的否决条件。

上述内容现已按《六壬大全》正文写入 `PanzhuRule::definition()['judgments']`，作为课经详情页的完整静态课义：明确有利者标为增强，明确不利者标为减损，只说明远近、动静者保持中性。它们仍不参与主体 matcher。

当前盘是否实际触发这些修证尚未全部程序化，因此动态 `RuleMatch.evidence['judgments']` 暂不伪造命中；相应边界继续保留在 `uncovered`。这不影响详情页完整列出古籍条件，也不影响盘珠课主体与天心、回还两格的冻结结论。

## 九、候选规则比较

| 候选 | 逻辑 | 结论 |
| --- | --- | --- |
| A | 四建与三传全部在四课整体地支集合 | **正式采用**，与正文主定义、正文盘珠例一致 |
| B | 只检查四课上神 `sike[1,3,5,7]` | 否决；会排除正文天心格乙巳日例 |

## 十一、回归边界

测试必须锁住以下边界：

1. `sike[0]` 日干不得误当同索引地支；
2. 第三课下位等非上神位置属于“四课之中”；
3. 仅回还格成立时不得升级为盘珠；
4. 《订讹》“四建俱在三传”可以独立成立天心格，但不得单独升级为盘珠；
5. 盘珠主体必须同时满足四建尽在四课与三传尽在四课；
6. 2031-01-24 01:00 的生产盘必须真实命中盘珠、天心、回还三项。
7. `PanzhuRule::definition()` 必须完整列出三条主体成立条件及正文吉凶、远近、动静修证，详情页不得回退为“尚未结构化录入”。
8. 静态课义不得反向收紧 matcher；尚未程序化的动态修证必须继续留在 `uncovered`，不得伪造为当前盘已触发。
