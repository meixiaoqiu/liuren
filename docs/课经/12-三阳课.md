# 三阳课整理笔记

## 古籍标准

《六壬大全》的三阳标准可整理为：贵人顺行，日辰在天乙前，发用旺相。

《六壬大全》卷二另明定天乙贵人的结构：贵人居中，贵前五将为螣蛇、朱雀、六合、勾陈、青龙；贵后六将为天空、白虎、太常、玄武、太阴、天后。因此“日辰在天乙前”不是任意的圆周距离，而是日干寄宫与日支所在宫位均乘贵前五将之一。

## 程序化条件

1. 贵人顺行。
2. 日干寄宫所在的地盘宫位乘贵前五将之一。
3. 日支所在的地盘宫位乘贵前五将之一。
4. 发用得季节旺相。

日干、日支本身不额外要求季节旺相；旺相条件落实在发用。

## 标准课例核对

原例为乙丑日、酉时、戌将，并称“天乙子临亥顺行”：

- 若以子贵临亥起将，乙寄辰乘青龙，为贵前第五将。
- 日支丑乘朱雀，为贵前第二将。
- 寅加丑发用；戌将期间属于春季，寅木旺。

所以该例的三阳内部结构完全符合上述四项条件。

在当前历法中可用 `2004-04-16 18:00` 复现：乙丑日、酉时、戌将，北京当日日落约在 `18:53:26`，因此仍用昼贵子；天乙子临亥顺行，三传寅、卯、辰，完整成立三阳课。

## 研究中遇到的问题

- 原例在酉时使用乙日昼贵子。《大全》卷九又明言应推究节气日出日入，不应把卯酉简单视为固定分界，因此酉时日落之前仍可使用昼贵。
- 曾根据另一条后世课例把“贵前”误推为六个宫位；《大全》卷二已有贵前五将的直接定义，因此废弃该推断。

## 最终处理

- 三阳规则严格采用贵前五将，不采用“贵人前六宫”。
- 昼夜贵改按北京经纬度的当日实际日出日落切分，时区固定为 UTC+8。
- 前台直接显示日干寄宫和日支各自所乘的贵前天将及其序次，避免“贵人之前第几位”的歧义。
