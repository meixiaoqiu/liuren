# 第二十八课：和美课

## 当前结论

和美课主体暂按《六壬大全》正文课例能够直接验证、并与《观月经》“四和美”前三式相合的最小口径实现。规则为三路 OR：

1. 日干寄宫与支上神六合，并且日支与干上神六合；
2. 日干寄宫与干上神六合，并且日支与支上神六合；
3. 干上神、支上神与三传中的任意一传共同构成完整三合局。

精确公式：

```text
cross = 六合(日干寄宫, 支上神) AND 六合(日支, 干上神)
same  = 六合(日干寄宫, 干上神) AND 六合(日支, 支上神)
upper_sanhe = EXISTS 传 IN 三传: 三合(干上神, 支上神, 传)

和美课 = cross OR same OR upper_sanhe
```

## 原文与正文课例

《六壬大全》卷八《课经集（二）·和美课》：

> 凡课干支遇三合、六合，上下递互相合，曰和美课。

> 如壬午日巳时丑将占，戌加寅为用，三传戌午寅，干上未与中传作六合，传逢三合，日辰上下作三合，日辰旺气，传输得用为合，和美课也。

现代复现时间：`2026-01-08 09:00`。盘面为壬午日、巳时、丑将，三传戌午寅。其四课关系为：

- 日干壬寄亥，支上神寅：寅亥六合；
- 日支午，干上神未：午未六合。

因此正文唯一课例完整命中第一路“交互合”，无需借用《订讹》宽入口才能成立。这是选择当前主体规则最重要的实证。

## 《观月经》结构

现代《图解六壬大全》整理出的前三式为：

1. 日干与支上神作合，日支与干上神作合；
2. 日干与干上神作合，日支与支上神作合；
3. 干支上神与三传作三合。

本实现把“日干”落实为日干寄宫，把第三式落实为干上神、支上神与三传任一支构成完整三合。三式结构对称，且第一式与正文课例逐项闭合。

《观月经》第四式“四课上下俱作三合”尚未得到足够清晰的程序语义，暂不实现。

## 《订讹》扩大口径归档

《订讹》还出现以下结构：干上神与支上神单独六合、干上神与日支单独六合、干上神与日干寄宫单独六合、支上神与日支单独六合、三传自成三合后干支上见六合，以及三合局生日或作财。

上一版把这些全部设为独立 OR 入口，720 核心盘命中 `251/720`（34.86%），2026 年命中 `1525/4380`（34.82%）。该比例不能反向证明规则错误，但说明宽口径显著削弱课名区分度；更重要的是，它超过正文课例能够直接证明的范围。因此本轮将这些内容保留为扩展口径研究材料，不进入主体判断。

《订讹》的具体例子仍保存在 `/kejing` 的 `source_examples` 中，不再作为可执行主体课例。

## 当前未覆盖

- 《观月经》第四式"四课上下俱作三合"；
- 《订讹》的单边六合与"三传三合、生日作财"等扩大入口；
- 还魂债、合带六害或空亡、蜜中砒等增强或减损结构；
- 正文"日辰旺气"的课义增强判断。
