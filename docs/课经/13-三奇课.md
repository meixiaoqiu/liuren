# 第十三课：三奇课

## 《六壬大全》原文口径

“凡课得旬日之奇，发用或入传，为三奇课。”结合后文“有旬奇，无日奇，亦可用”及标准课例“旬奇发用为三奇课”，当前以旬奇作为成课的必要条件，日奇作为课内等级依据。

旬奇分配：

- 甲子、甲戌旬用丑；
- 甲申、甲午旬用子；
- 甲辰、甲寅旬用亥。

日奇分配：甲午、乙巳、丙辰、丁卯、戊寅、己丑、庚未、辛申、壬酉、癸戌。

## 编程判断

1. 由占日干支确定它在六十甲子中的序号及所属六甲旬；这里的旬是日旬，不取月旬或年旬。
2. 取得该旬的旬奇和该日干的日奇。
3. 旬奇进入三传之一，即为三奇课；只有日奇而无旬奇，不判三奇课。
4. 旬奇、日奇同时入传，只记录为原文所说的上等条件，不另造课名。
5. 三传恰为亥、子、丑，只在三奇课的推理信息中标记原文所称“三奇联珠”，不自创为格。

## 标准课例与核对

《大全》举“乙酉日，未时，申将”，三传亥、子、丑。乙酉占日属于甲申旬，旬奇为子；子入中传，因此命中三奇课。亥、子、丑俱全，推理信息标记为原文所称“三奇联珠”。乙日奇为巳，本例没有日奇，正好验证原文“有旬奇，无日奇，亦可用”。

## 尚未扩入基础规则的增强条件

原文另论旬奇、日奇并见为上，以及天上三奇乙丙丁、地下三奇甲戊庚入传尤利。这些属于三奇课的层次判断，不改变基础课名；当前先记录，不把遁干条件混入基础命中规则。
