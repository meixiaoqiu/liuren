# 第三十一课：游子课

## 底本与来源

主体据《六壬大全》卷八《课经集（二）·游子课》（识典古籍 SK1599）校录。正文、象曰、正文课例与同页附录分别记录，不把旁证的较宽口径静默并入正文主体。可核验链接：

- 《六壬大全·游子课》：https://www.shidianguji.com/book/SK1599/chapter/1k1lqkvtq8m4q
- 《古今图书集成·艺术典》所录同文：https://www.shidianguji.com/mid-page/7597555539304677414

## 《六壬大全》正文

> 凡课三传皆土，遇旬丁天马为用，曰游子课。盖土者，辰戌丑未，季神归墓，五行之时，主巡游考绩之期。旬丁者，每旬丁干所值之神，主摇动，事最速。天马者，正月起午，顺行六阳位也。又为驿递之神，身势摇动，使人好游，故名游子。居者占之欲游，游者欲还家也。统观之体，乃云萍聚散课也。

## 象曰

> 丁马加季，奔走西东。出行吉利，坐守困穷。疾病难产，官讼多凶。天阴不雨，婚事胡从。

正文后续以传出阳神、传入阴神，以及与斩关、淫泆、天寇、行年、五墓四杀、三奇六仪等并见说明出入方向、吉凶增减与救解；这些未作为主体成立条件。

## 正文课例

> 如三月将乙巳日午时，三传土，遇丁马，用为游子课。

课例三传为未→戌→丑。乙巳属甲辰旬，旬丁为丁未，故旬丁未发用；三月月建辰，月内天马为戌，位于中传。

生产 `PanCalculator` 以北京时间 `2022-04-22 11:00:00` 复现：甲辰月、乙巳日、午时、谷雨后酉将，三传未→戌→丑。该课按项目严格口径由旬丁发用成立；天马只在中传，不属于天马发用。

## 其他文献旁证

### 《订讹》

“三传皆土，又或见旬丁，或见二马”，偏向旬丁、二马以 `OR` 相连，并使用较宽的“见”。

### 《观月经》

“三传皆四季”，支持只要求三传皆季的更宽传统，但属于独立文献口径。

### 《心镜》

“四季三传有六丁，不然天马又相并”，偏向旬丁与天马二者 `OR`。

### 《袖中金》

“三传俱季名曰游子”，同样支持只要求三传皆季的较宽传统。

### 《六壬粹言》及其他旁证

“三传皆季神，或见旬丁，或见天马”，明确支持旬丁、天马 `OR`。这些旁证说明 `OR` 有较强依据，但“见”是否足以推翻《大全》正文“为用”，证据仍不足，故项目暂不采用只需任意入传的候选 B。

## 候选规则与正文课例约束

| 候选 | 精确逻辑 | 取舍 |
| --- | --- | --- |
| A | `allJi && (initial == xunDing || initial == monthTianma)` | 项目采用；同时保留“三传皆土”和“为用” |
| B | `allJi && (xunDing IN transmissions || monthTianma IN transmissions)` | 不采用；把“为用”主动放宽成任意入传 |
| C | `allJi` | 不采用；删除正文丁马条件 |
| D | `allJi && xunDing IN transmissions && monthTianma IN transmissions && (initial == xunDing || initial == monthTianma)` | 不采用；增加正文未明示的“丁马必须同时入传” |

正文课例中初传未为旬丁、中传戌为天马，故 A、B、C、D 都通过；一个课例不能区分四者。它只能排除“旬丁和天马必须同时发用”的解释，因为旬丁未与天马戌不是同一支。

## 项目最终实现

```text
游子课 =
  三传全部属于辰、戌、丑、未
  AND（旬丁发用 OR 月内天马发用）
```

布尔公式：

```text
allJi && (initial === xunDing || initial === monthTianma)
```

四季直接固定为 `{丑1, 辰4, 未7, 戌10}`。旬丁为 `dayXunHeadBranch() + 3` 后取十二支余数。月内天马按 `yuezhi` 固定映射，正月寅起午、逐月顺行六阳位；不用月将，也不是驿马。

这是本项目当前最严格、最保守的可执行解释，不是声称古籍已经彻底消除了所有语义歧义。

## 枚举旁证

720 核心结构不含月份维度：

- 三传皆季：39 / 720。
- 三传皆季 + 旬丁发用：6 / 720。
- 三传皆季 + 旬丁只需入三传：12 / 720。

A 依赖 `yuezhi`，不能给出脱离月份的唯一 720 命中数。按月代入同一批 720 核心结构：

| 月份 | 天马 | A 命中 |
| --- | --- | --- |
| 正月／七月 | 午 | 6 / 720 |
| 二月／八月 | 申 | 6 / 720 |
| 三月／九月 | 戌 | 13 / 720 |
| 四月／十月 | 子 | 6 / 720 |
| 五月／十一月 | 寅 | 6 / 720 |
| 六月／十二月 | 辰 | 13 / 720 |

以十二个月作为维度，分母为 `720 × 12 = 8640`：A = 100 / 8640，B = 220 / 8640，C = 468 / 8640，D = 14 / 8640。三、九月 B = 38 / 720，而 C = 39 / 720，说明当天马为戌时 B 几乎退化为“三传皆季”。这些数量仅作规则辨析旁证，命中少不构成 A 正确的古籍证明。

## 尚存歧义与未覆盖

目前不知道：若三传皆季，旬丁或天马只在中传、末传，而初传既非旬丁也非天马，《六壬大全》正文是否仍认作游子课。当前实现选择不放宽；未来若发现可靠正文课例明确是丁／马只居中末传且仍称游子课，应重新评估 A → B。

程序尚未实现：

- “传出阳神欲远行，传入阴神欲私归”的出入方向细分；
- 与斩关、淫泆、天寇、行年、五墓四杀及三奇六仪等合课、凶吉增减与救解条件。
