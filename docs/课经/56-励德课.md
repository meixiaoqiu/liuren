# 56 励德课

## 一、冻结结论

课级 matcher 只采用《六壬大全》正文与《订讹》共同给出的宽定义：

```text
励德课成立：
    天乙贵人所临地盘 ∈ {卯, 酉}
```

布尔公式：

```text
is_lide = noblemanGroundPosition() in {卯, 酉}
```

四课阴阳神相对贵人的前后关系不再追加为课级必要条件，而是在励德课成立后继续分型：

- 日辰阴阳四神全部在贵后六将：微服格；
- 日辰阴阳四神全部在贵前五将：蹉跎格；
- 两阳神在贵前、两阴神在贵后：`yang_front_yin_rear` 吉凶判断；
- 两阴神在贵前、两阳神在贵后：`yin_front_yang_rear` 吉凶判断；
- 其余混合状态（包括某神正乘贵人）：仍然是励德课，只是不强套四种完整分型。

## 二、《六壬大全》正文

可核验来源：

- 识典古籍《六壬大全·励德课》：https://www.shidianguji.com/book/SK1599/chapter/1k1lql3qjqa0i
- 维基文库《古今图书集成·艺术典》第728卷「励德课」：https://zh.wikisource.org/zh-hans/%E6%AC%BD%E5%AE%9A%E5%8F%A4%E4%BB%8A%E5%9C%96%E6%9B%B8%E9%9B%86%E6%88%90/%E5%8D%9A%E7%89%A9%E5%BD%99%E7%B7%A8/%E8%97%9D%E8%A1%93%E5%85%B8/%E7%AC%AC728%E5%8D%B7
- CText《六壬大全》卷十相关段落：https://ctext.org/wiki.pl?chapter=611073&if=en&remap=gb

正文首句：

> 凡天乙立卯酉，为励德课。

正文又说卯酉为阴阳交易之位，贵人由此迁易，统《随》之体。

因此课级必要条件在首句已经完整给出：**天乙立卯酉**。

## 三、《订讹》旁证

《订讹》直接概括：

> 励德：贵人临卯酉。

随后才解释干支阴神、阳神在贵人前后的尊卑进退。其语法层级同样支持：

```text
先判：贵人临卯酉 → 励德
再判：四课阴阳神前后 → 具体应象
```

而不是：

```text
贵人临卯酉
AND 必须落入某一种完整前后组合
```

## 四、贵前、贵后的精确程序语义

《心镜》校语明确说：

> 励德言前后者，指天将而言。

并引：

> 天乙居中，后六前五。

因此前后按十二天将固定次序判断，不按地支顺逆距离自行推导：

```text
贵前五将：
螣蛇、朱雀、六合、勾陈、青龙

贵人：
居中，不属于前或后

贵后六将：
天空、白虎、太常、玄武、太阴、天后
```

项目已有三阳、三阴规则使用同一口径。本课必须复用这个定义。

## 五、四课阴阳神的程序映射

项目四课数组为：

```text
[日干, 第一课上神, 第一课上神, 第二课上神,
 日支, 第三课上神, 第三课上神, 第四课上神]
```

因此：

| 古籍术语 | 程序位置 |
| --- | --- |
| 日阳 | 第一课上神 `sike[1]` |
| 日阴 | 第二课上神 `sike[3]` |
| 辰阳 | 第三课上神 `sike[5]` |
| 辰阴 | 第四课上神 `sike[7]` |

每一神的「前、后、居中」取其所乘天将判断。

## 六、为什么不能把“四段”写进 matcher

《心镜》确有“四段定之”的整理：

1. 四神俱前：蹉跎；
2. 四神俱后：微服；
3. 阳前阴后；
4. 阴前阳后。

但《大全》自己的首个标准课例已经证明，这四段不能成为“励德是否成立”的穷尽门槛。

正文例：

```text
戊子日 申时 午将 占昼
丑贵加卯
```

现代生产完整复现：

```text
2022-08-03 16:00
```

四课为：

```text
日阳：卯，乘朱雀 → 贵前
日阴：丑，乘贵人 → 居中
辰阳：戌，乘玄武 → 贵后
辰阴：申，乘白虎 → 贵后
```

其中日阴正乘贵人，既非前也非后，所以此例不属于四种完整分型中的任何一种。

然而《大全》正文明确说：

> 丑加卯，为励德也。

因此：

```text
四段 = 励德成立后的分型
≠ 励德课级必要条件
```

这是冻结宽 matcher 的关键反证。

## 七、微服格

正文：

> 如日辰阴阳俱在天乙后，为微服格。

现代生产复现：

```text
2019-12-30 04:00
辛丑日，寅时，丑将，夜贵寅加卯
```

四神：

```text
日阳酉 → 白虎 → 贵后
日阴申 → 天空 → 贵后
辰阳子 → 太阴 → 贵后
辰阴亥 → 玄武 → 贵后
```

因此正式格规则：

```text
is_weifu =
    is_lide
    AND 日阳∈贵后
    AND 日阴∈贵后
    AND 辰阳∈贵后
    AND 辰阴∈贵后
```

## 八、蹉跎格

正文：

> 如日辰阴阳俱在天乙前，为蹉跎格。

现代生产复现：

```text
2019-01-23 04:00
庚申日，寅时，子将，夜贵未加酉
```

四神：

```text
日阳午 → 螣蛇 → 贵前
日阴辰 → 六合 → 贵前
辰阳午 → 螣蛇 → 贵前
辰阴辰 → 六合 → 贵前
```

因此：

```text
is_cuotuo =
    is_lide
    AND 日阳∈贵前
    AND 日阴∈贵前
    AND 辰阳∈贵前
    AND 辰阴∈贵前
```

## 九、两种完整前后组合

《象曰》直接给出：

```text
阳前阴后：
    日阳、辰阳 ∈ 贵前
    AND 日阴、辰阴 ∈ 贵后
    → 君子则吉，小人则危

阴前阳后：
    日阴、辰阴 ∈ 贵前
    AND 日阳、辰阳 ∈ 贵后
    → 小人得意，君子失机
```

这两类作为 `LideRule` 的 `judgments`，不另造格名，也不反向决定励德课是否成立。

## 十、结构枚举

独立结构枚举口径：

```text
60 个合法日干支
× 12 种天地盘偏移
× 昼贵 / 夜贵
= 1440 种结构状态
```

结果：

| 类型 | 数量 |
| --- | ---: |
| 励德总数：贵临卯或酉 | 240 |
| 微服 | 16 |
| 蹉跎 | 15 |
| 阳前阴后 | 20 |
| 阴前阳后 | 12 |
| 其余混合状态 | 177 |

四种完整分型合计：

```text
63 / 240 = 26.25%
```

其余混合状态：

```text
177 / 240 = 73.75%
```

因此若把“四段之一”追加进课级 matcher，会删除约四分之三的励德结构，并直接排除《大全》戊子标准例。

本课另提供 `tests/Support/Statistics/LideStatistics.php`，用生产 `PanCalculator` 扫描 2026 全年每日十二个代表时辰，供后续复核真实时间口径下的命中率和各分型数量。

## 十一、最终实现

正式规则：

```text
LideRule:
    noblemanGround ∈ {卯, 酉}
```

独立格：

```text
WeifuRule:
    Lide
    AND 四神全部贵后

CuotuoRule:
    Lide
    AND 四神全部贵前
```

励德内部 judgments：

```text
yang_front_yin_rear
yin_front_yang_rear
```

贵人本身固定记作 `center`；绝对不能塞进贵前或贵后。

## 十二、回归边界

测试必须锁定：

1. 贵人临卯或酉即可命中；
2. 贵人不临卯酉时，即使其他结构相似也不得命中；
3. 戊子正文例中日阴乘贵人，仍命中励德；
4. 微服四神必须全部贵后；
5. 蹉跎四神必须全部贵前；
6. 阳前阴后、阴前阳后只进入 judgment；
7. 贵人自身必须记作居中；
8. 本课实现不得修改排盘核心、昼夜贵、天将顺逆或 720 fixture。
