# 第二十七课：合欢课

> **当前状态：采用《六壬大全》正文标准课例能够直接支持的最小严格口径。** 《订讹》扩展出的多种合式作为异体研究记录，暂不扩大正文主体规则。

## 《六壬大全》原文

出处：《六壬大全》卷八《课经集（二）·合欢课》。底本见 <https://www.shidianguji.com/book/SK1599/chapter/1k1lqkvtq6ia2>，对照本见 <https://zh.wikisource.org/wiki/六壬大全/8>，节录见 <https://zh.wikisource.org/wiki/欽定古今圖書集成/博物彙編/藝術典/第726卷>。

> 凡课日辰遇天干作合，及支三合六合发用，并占人年命俱乘吉将，为合欢课。天干合者，甲己为中正合，乙庚为仁义合，丙辛为威权合，丁壬为淫讹合，戊癸为无情合。六合者，子合丑实，丑合子空；亥合寅就，寅合亥破；戌合卯旧，卯合戌新；辰合酉合，酉合辰离；巳合申顺，申合巳逆；未合午晦，午合未虚。三合者，亥卯未繁冗驳杂，巳酉丑矫革离异，寅午戌党侣未正，申子辰流而不清、滞而不竭、宜动不宜静。凡日辰年命见合，主和合，合则新，则人欢事成，故名合欢课，统井之体，乃婚姻团圆之课也。

象曰：

> 乾坤匹配，奇偶交并，占孕迟生，行人荣省，名利乔迁，财喜欢称，婚姻天缘，万事佳庆。如三合，事关众，克应过月。六合，阴阳配，夫妇和顺。或日辰阴阳年命六处，传逢吉将，四杀没，合多吉多，凡事成就顺利，行无不吉。从凶杀亦主凶中和合，或合带刑害，有德在末有气，乃入凶遇吉，可以小用宛转。或二阴作合，求婚大吉，当应上六井收勿幕有孚元吉之象。若占凶事，守旧愈迟疑。求文书干事，见合无气，终滞，似不决意，不若不见为妙。占病凶将尤甚，传进病难退。占失脱，藏匿难获。或合带刑冲破害，合而藏祸，内吉外凶。合空事费力难济，传退连茹，合带暗鬼克日，乘蛇虎雀有害，不可意外狂图，及托人干事，当应九二井谷射鲋之凶象也。

> 如戊申日子时申将，子与干上丑作六合，加辰发用。戊日天干上丑遁得癸作合，支辰与三传合作三合，亥命见未为贵人，行年在辰见子为青龙，日辰阴阳上下作三合，四杀没于四维，又乘吉将，为合欢课。

## 一、当前生产规则：正文最小严格口径

> **合欢课成立必须同时满足以下三项：**
> 1. **天干作合**：日干上神（地盘日干寄宫位的上神）按本日所在旬寄宫天干，与日干作天干五合（甲己、乙庚、丙辛、丁壬、戊癸）。
> 2. **支三合与六合发用（同时成立，AND 逻辑）**：
>    - (a) 初传与干上神作地支六合（子丑、寅亥、卯戌、辰酉、巳申、午未）；**且**
>    - (b) 初传必须参与，并与日支及中传或末传共同构成完整地支三合（亥卯未／巳酉丑／寅午戌／申子辰）。
> 3. **占人本命宫上神属于六吉将之一（贵人、六合、青龙、太常、太阴、天后）** 且 **行年宫上神属于六吉将之一**。

**精确公式**：

## 二、为什么采用正文最小严格口径

### 1. AND 选择的依据

主体定义"凡课日辰遇天干作合，**及**支三合六合发用"用"及"字作为连接词，不写"或"。同时：

- 课例"戊申日子时申将"**同时具备**六合（子丑）与三合（申子辰），无法从课例区分是 AND 还是 OR；
- 旁证材料中"**或**日辰阴阳年命六处传逢吉将"是象曰对"六处"的连接词用法，主体定义本身的连接词是"及"，不应用"或"覆盖。

六合 OR 三合的扩大口径作为异读保留，本轮**未采用**。

### 2. 三合判定的依据

原文"支三合六合发用"中的"发用"明确指初传，因此初传必须参与三合；原文没有限定第三支必须来自中传或末传，二者任一均可。

具体算法：分别检查“日支 + 初传 + 中传”和“日支 + 初传 + 末传”是否为完整三合。标准例为日支申、初传子、末传辰；如果另一盘由日支申、初传子、中传辰组成三合，也同样符合原文。四组三合支序列为：
- `[0, 4, 8]` = 申子辰（水局）
- `[1, 5, 9]` = 巳酉丑（金局）
- `[2, 6, 10]` = 寅午戌（火局）
- `[3, 7, 11]` = 亥卯未（木局）

## 五、课例"戊申日子时申将"的复现（**部分复原**）

| 维度 | 课例 | 2000-06-19T00:00:00 |
| --- | --- | --- |
| 日干支 | 戊申 | 戊申 ✓ |
| 占时 | 子时 | 00:00 ✓ |
| 月将 | 申 | 申（节气对应"芒种"，非"夏至后到处暑前"） |
| 干上神 | 丑（寄癸） | 丑（甲辰旬中丑寄癸）✓ |
| 三传 | 子 申 辰 | 子 申 辰 ✓ |
| 本命 | 亥命（盘亥上=未贵人） | 1959 己亥年男，本命=亥，盘亥上=未贵人 ✓ |
| 行年 | 课例"辰"（本项目行年=未） | 2000 庚辰年 1959 男命行年=未，盘未上=卯太常（项目公式下） |

**月将"申"对应节气区间更正**：经核实项目 `$jieqi2Yuejiang[10] = 8 = 申` 对应节气索引 10，按 Tyme `getTerm()->getIndex()` 顺序对应"芒种"（约 6 月 5 日到 6 月 21 日），**不是**"夏至后到处暑前"。2000-06-19 落在 2000 年芒种（6月5日 20:24）到夏至（6月21日 13:33）之间，属"芒种"。

### "行年在辰"的口径问题（重要诚实边界）

课例"亥命见未为贵人，行年在辰见子为青龙"——按本项目 `FateCalculator`（男一岁起丙寅顺行）：

- 2000 年（庚辰，索引 16）起课时，本命=亥（己亥年，索引 35）→ 行年索引 = (2 + (16 − 35 + 60)) % 60 = 43 → 行年支 = 43 % 12 = 7 = 未。

故"亥命"与"行年支=辰"在 2000 年按本项目公式不可同时成立（戌年生人始能行年=辰，亥年生人行年必非辰）。

**复现策略**：保留课例"亥命+贵人"的明示结构（1959 己亥年男），用"行年=未、宫上神=卯乘太常"作为课义"年命俱乘吉将"的等价实例——两者都满足主体条件"行年宫上神乘六吉将"。但**这不是完整复原**，因为"亥命+辰行年"这一具体年命结构无法在 2000-2026 范围内同时成立。

`KeJingCatalog` 案例已明确标注为"部分复原"（描述文案中说明）。

- **初传**：子（与干上丑作子丑六合 → 支六合发用 ✓）；日支申、初传子、末传辰作申子辰三合 → 支三合发用 ✓；
- **占人补充资料**：`1959-06-21T12:00:00` 男（**现代补充资料**，不是古籍原例所载）：
  - 1959 己亥年，本命=亥；

  - 地盘未上神=卯（太常）→ 行年宫乘吉将 ✓。

- **匹配路径**：初传子与干上丑六合；日支申、初传子、末传辰构成申子辰三合。

## 八、前台推理展示

`hehuan-trace.blade.php` 五段：

1. **天干作合**：日干 → 寄宫位 → 上神 → 旬寄宫天干 → 是否与日干作天干五合；
2. **初传与干上神作地支六合**：初传、干上神、六合对 → 是否成立；
3. **支三合发用**：分别检查日支、初传、中传及日支、初传、末传，展示命中的三合局；
4. **本命宫上神**：地盘本命支 → 宫上神 → 乘天将 → 是否六吉将；
5. **行年宫上神**：地盘行年支 → 宫上神 → 乘天将 → 是否六吉将；
6. **最终结论**：成立 / 不成立 / 尚未判断，标明通过哪两条路径同时命中。
