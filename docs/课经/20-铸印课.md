# 第二十课：铸印课

## 《六壬大全》原文与课例

出处：《六壬大全》卷八《课经集（二）·铸印课》。底本见 https://www.deeporacle.ai/dianji/liuren-daquan/121-zhu-yin-ke ，对照本见 https://www.xunqihuang.com/book/chapter/c6b2e009dc84233d.html 。

原文：

“凡课得戌加巳中传，为铸印课。戌天魁也，为印；巳太乙也，为炉。盖戌中有辛金，与巳中丙为作合，全凭火炼，铸成贵器，为符印，故名铸印。占者符命入手，官增权柄，统鼎之体，乃炼药成丹之课也。”

课例：

“如丙子日未时子将，巳加子用，传遇天魁，末乘太常，为铸印课。”

课例四课（右起）：丙上戌、戌上卯、子上巳、巳上戌。三传为巳、戌、卯（初巳、中戌、末卯），末传卯乘太常；其中“巳上戌”即天盘戌加临地盘巳（“戌加巳”）。

## 成课条件口径辨析

正文“凡课得戌加巳中传”存在不同解读，落成五个口径。各口径在 720 核心基线（12 种天地盘关系 × 60 个日干支）上的命中如下：

| 口径 | 条件 | 命中课数 |
| --- | --- | --- |
| A | 三传依次巳、戌、卯 + 天盘戌加巳 | 17 |
| B | 中传戌加巳 + 传见卯 | 17 |
| C | 中传戌加巳 | 17 |
| D（本实现采用） | 三传同时含戌与巳 | 46 |
| E | 天盘戌加巳 + 三传含戌含巳 | 27 |

包含关系：D(46) ⊃ E(27) ⊃ A(17)，且 A = B = C(17)。

### “戌加巳”的两种理解

- 天地盘关系：天盘戌加临地盘巳（课例四课“巳上戌”）。
- 三传关系：三传同时出现戌与巳（对应口径 D）。

### 采用口径 D 的理由

1. 原文“戌加巳中传”的“发用”与“中传”历来有歧义：后人歌诀作“铸印发用戌加巳”，以“发用”称戌加巳；但正文作“戌加巳中传”，课例“巳加子用，传遇天魁”又明确发用为巳、传遇天魁（戌）。口径 D 取“戌、巳同入三传”，不再预先规定戌为中传、卯为末传，避免在“发用/中传”的争议上预先选边。

2. 口径 D 条件最少、最贴近“戌、巳同现于三传”的字面，命中 46 课；A/B/C 三个更严格的口径收敛到同一批 17 课，E 口径（加“戌加巳”）为 27 课。

### 待评估问题

1. “戌加巳”应理解为“天盘戌加临地盘巳”（天地盘关系），还是“三传同时出现戌和巳”（三传关系）？
2. “中传”是否要求戌必须位于三传第二位？还是仅表示“戌入三传”即可？
3. 口径 E（戌加巳 + 三传含戌含巳）命中 27 课，是否符合原文本意？
4. 各口径的等价/包含关系是否只在 720 核心基线内成立、是否具有一般性？
