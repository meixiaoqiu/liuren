# 三光课整理笔记

## 古籍标准

《六壬大全》以日、辰、用神得时旺相，并且三处所乘皆为吉将，判为三光课。这里的“旺相”采用四时旺相，不直接以月支逐月定义：春木旺火相，夏火旺土相，秋金旺水相，冬水旺木相；每季结束前十八日另作土旺金相。

## 程序化条件

1. 日干得季节旺相。
2. 日支得季节旺相。
3. 发用得季节旺相。
4. 日上神、辰上神、发用三处均乘吉将。

## 研究中遇到的问题

- 古籍给出四时和季末土旺十八日，但没有规定现代钟表意义上的精确交界时刻。
- 早期曾误认或误录部分课例的日干支，导致反推结论不可靠；重新核对原文后废弃了这些推断。
- “月令旺相”容易被理解为按十二个月逐月判断，实际采用的是四时旺相体系。

## 最终处理

- 四季以四立的精确交节时刻为界。
- 每一季的土旺期，从下一个四立交节时刻向前推十八个整日。
- 这是将古籍“十八日”落实到现代时间输入的程序口径，并非古籍明文规定到时分秒。
- 前台使用“季节旺相”表述，避免写成“月令旺相”。
