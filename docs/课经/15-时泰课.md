# 第十五课：时泰课

## 《六壬大全》原文与课例

“凡课用起太岁、月建，乘青龙、六合，又带财德之神，为时泰课。”课经随后明确初末可以是“初传青龙，末传六合”，也可以青龙、六合互换。

《大全》仅给出一则完整课例：子年戌月戊寅日，三传子、巳、戌。太岁子发用兼为日财，月建戌入末传；初传青龙、末传六合，日德巳入中传。

本节后的“订讹”另说：“但逢太岁、月建作日财德，太岁发用更佳，入传亦可。”其中“更佳”表明太岁发用不是成立门槛，太岁进入中传或末传也可以成立。

## 编程判断

程序暂按正文、象曰后说明、标准例及订讹综合识别：

1. 初传乘青龙、末传乘六合，或者初传乘六合、末传乘青龙。
2. 太岁或月建至少一个进入三传，不限制传位。
3. 入传的太岁或月建至少一个兼作占日之日财或日德。
4. 三组条件同时成立，才判时泰课。

太岁、月建是否发用只作为“更佳”状态，不参与是否成立的判断；进入中传或末传亦可。象曰后的“太岁、月建、月将，并财德合吉神，则为福神相助”暂按加吉说明理解，不单独以月将成立时泰课。此口径作为当前编撰阶段的暂定结论，不继续混入其他书目的异说。

《毕法补谈》另有“月建发用，乘吉神生合日干年命上神”也称时泰的简化口径。当前六十四课编撰以《六壬大全》课经正文为准，暂不混入该异说。

## 可执行标准课例

《大全》课经举“子年戌月戊寅日戌时卯将”，三传子、巳、戌：子为太岁兼戊日之财，巳为戊日德，戌为月建；初传乘青龙，末传乘六合。

在当前历法中可用 `1900-11-01 20:00` 重现这一结构。


## 象

课入时泰，皇恩欲拜。灾患潜消，谋为无碍。逃亡必归，盗贼自败。孕育贵儿，前程浩大。
