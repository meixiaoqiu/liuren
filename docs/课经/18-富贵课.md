# 第十八课：富贵课

## 《六壬大全》原文与课例

“凡课得天乙乘旺相气，上下相生，更临日辰年命发用，为富贵课。”天乙为十二天将之首，旺相而发用，又得上下相生并临日辰年命，故主富而且贵，统大有之体。

《大全》标准例为二月辛巳日丑时、戌将，寅命、行年巳。三传寅、亥、申，初传寅乘天乙；二月木旺，寅得旺气；天盘寅临地盘巳，木生火；地盘巳又同时是日支与行年，故成立富贵课。

## 编程判断

程序按课经正文识别：

1. 初传必须乘天乙贵人。
2. 初传必须得当时季节旺气或相气。
3. 初传所在的天盘支与其所临地盘支，五行须有一方生另一方。
4. 初传所临地盘须为日干寄宫、日支、本命或行年至少一项。
5. 四组条件同时成立，才判富贵课；实际命中的日辰年命来源逐项展示。

太常为绶、驿马乘青龙均为增强条件，不作为富贵课成立门槛。贵人临辰戌为入狱，属于课义减损；原文另有乙辛日、辰戌日或辰戌年命不以坐狱论的例外，亦不改变基础课名是否成立。命中例外时仍保留“贵人入狱”这一客观结构，并在其后显示“不以坐狱论”，最终仍按富贵课主体为吉。

《大全》另载“如戌加巳，则富贵权印之象，最吉”。项目曾按天盘戌加临地盘巳实现此增强条件，但在当前严格富贵课口径下进行可达性验证时，以1986年8月男性资料扫描至2126年无一例；另在2024至2040年间遍历男女及可用出生年份，仍无真实课例。手工拼装字段虽可触发判断，却不是排盘程序能够生成的真实盘。因此当前只保留原文及其歧义记录，不将“戌加巳”作为可执行课义；待以后确认它所从属的宽口径富贵课定义后再实现。

## 象

天降福德，万事新鲜。财喜双美，富贵两全。孕生贵子，婚配婵娟。狱讼得理，谋望胜前。
