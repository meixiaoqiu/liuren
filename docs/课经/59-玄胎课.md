# 59 玄胎课

## 一、冻结结论

主体 matcher：

```text
玄胎课 =
    初传 ∈ {寅, 巳, 申, 亥}
    AND 中传 ∈ {寅, 巳, 申, 亥}
    AND 末传 ∈ {寅, 巳, 申, 亥}
```

《六壬大全》正文“孟神发用，传皆四孟”与《心镜》“三传俱孟是玄胎”、《订讹》“四孟神作三传”互相印证。

“孟神发用”不再增加第四个程序条件：发用就是初传，而“三传俱孟”已经要求初传属于四孟。

本课另将三种传统分型结构化为 judgments，不加入主体 matcher：

```text
病胎 = 玄胎 AND 进步长生
生胎 = 玄胎 AND 退步长生
绝胎 = 玄胎 AND 反吟
```

## 三、主体定义为什么是“三传俱孟”

正文定义：

> 凡孟神发用，传皆四孟，为玄胎课。

四孟为寅、巳、申、亥。

《订讹》直接作“四孟神作三传”；《心镜》又称“三传俱孟是玄胎”。三者没有实质冲突。

因此不采用以下扩大或收紧解释：

| 候选 | 结论 |
| --- | --- |
| 只要求初传为孟神 | 否决；遗漏“传皆四孟” |
| 三传全部属于四孟 | 正式采用 |
| 要求寅巳申亥四支全部出现 | 否决；三传只有三个位置，正文也没有要求四支齐备 |
| 另加“初传必须为某一指定孟支” | 否决；正文没有指定 |

## 四、正文课例

《六壬大全》正文：

```text
甲寅日寅时巳将占，三传申亥寅孟神，为玄胎课。
```

古籍没有给出唯一现代年份，因此目录把它作为《六壬大全》正文课例保存，不伪造唯一现代年月日。

项目已有一个真实生产盘可以稳定验证主体：

```text
2001-05-03 11:00
三传：申 → 亥 → 寅
```

该盘此前已经作为荣华课生产复现使用，三传字段已经由现有测试验证，因此本课复用它作为 executable 回归案例。

## 五、进步长生：病胎

《大全》正文与《订讹》在“快慢”上冲突。

结构：

```text
寅加巳
巳加申
申加亥
亥加寅
```

正文写“进步长生，主事迟”；《订讹》改为“主事速，又名病胎”。

《六壬灵觉经》也以进步为速、退步为迟，因此本项目：

```text
进步长生 → 病胎 → 主事速
```

程序检查整组天地盘对应关系，不把“主事速”并入成课条件。

## 六、退步长生：生胎

结构：

```text
寅加亥
亥加申
申加巳
巳加寅
```

《订讹》称退步长生，主事迟，又名生胎，并取“身临长生之乡，怀胎大吉”之义。

程序化为：

```text
退步长生 → 生胎 → 增强
```

## 七、反吟：绝胎

《订讹》玄胎段末明确：

```text
若反吟课，为绝胎。
```

《六壬灵觉经》亦称“反吟四孟为绝胎，主胎产之灾”。

项目已有正式 `fanyin` 盘型事实，因此：

```text
玄胎 AND hasPlatePattern('fanyin') → 绝胎
```

只作为减损判断，不否决玄胎课本身。

## 八、其他吉凶修证

以下均不加入主体 matcher：

- 财爻发用并得天后、生气、胎神：传统主妻有孕；
- 年命见相关胎孕结构：作为进一步修证；
- 喜神吉将：正文取吉；
- 老幼占病：正文取凶；
- 三刑及凶将：忧疑惊恐；
- 父母发用：尊长见灾；
- 子孙空亡：玄胎不育；
- 天后空亡：因孕伤母；
- 日用休囚等玄胎不育条件；
- 病讼、行人、捕贼等具体问事分类。

第一版只动态程序化病胎、生胎、绝胎；其余完整保留在 definition 与研究文档，等待对应公共算法和占事上下文成熟。

## 十、《六壬大全》完整原文

凡孟神发用传皆四孟为玄胎课。盖四孟者寅申巳亥四生之局，又为五行受气之位。如木生于亥，火子受气；水生于申，木子受气之类。此玄中有胎，故名玄胎。占者事皆新意，统家人之体，开花结子之课。

象曰：三传长生，胎孕成形；官加恩爵，婚获娉婷；病讼淹滞，财利叠兴；行人敌贼，恋生不行。恋生者，如寅加巳、巳加申、申加亥、亥加寅，为进步长生，主事迟。如用值天后财爻，主结偶怀胎；外有妻财值生气胎神发用，主妻有孕。如正月戊己日用子、四月庚辛日用卯、七月壬癸日用午，占妻怀孕无疑；或年命见之，遇玄胎尤的。或玄胎带喜神吉将吉，利远行及经求名利，百事皆吉，当应家人六四富家大吉之象。若老少占病，为后世投胎之兆，最凶。或常占遇三刑及凶神恶将，必有忧疑惊恐；父母用事，家中尊长见灾；或日用休囚，天后落空，为玄胎不育，家招干儿义女接续，当应九三妇子嘻嘻终吝之象。

如甲寅日寅时巳将占，三传申亥寅孟神，为玄胎课。

### 订讹

玄胎，四孟神作三传。三传长生为五行母气，此玄中有胎，故名玄胎。

占主事皆新意，有婴儿隐伏之象，最宜于产。求官求财求婚，皆以长生大利。病讼淹滞，行人不来，捕贼不获，恋生故也。若老幼占病，为后世投胎之兆凶。寅加巳、巳加申、申加亥、亥加寅，为进步长生，主事速，又名病胎；盖上生下，为五行病处，怀胎有忧。寅加亥、亥加申、申加巳、巳加寅，为退步长生，主事迟，又名生胎；盖下生上，乃身临长生之乡，怀胎大吉。发用财爻得天后，值生气胎神，定主妻有孕。如正月戊己日用子、四月庚辛日用卯、七月壬癸日用午，占妻怀孕无疑；年命见之尤的。常占遇三刑及凶将，必有忧疑惊恐。父母发用，尊长见灾。子孙空亡，为玄胎不育，凡占无成，更艰子息。天后空亡，因孕伤母。

此课虽系新鲜喜庆之兆，然多身喜心忧。盖为腹中有孕，心自悬悬也。事主远而多伏，暗昧不通，触则成祸。若反吟课，为绝胎。
