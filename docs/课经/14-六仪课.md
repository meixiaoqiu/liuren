# 第十四课：六仪课

## 《六壬大全》原文口径

“凡课得旬首之仪，发用或入传，为六仪课。”六旬分别以旬首的地支为旬仪：甲子旬用子、甲戌旬用戌、甲申旬用申、甲午旬用午、甲辰旬用辰、甲寅旬用寅。

原文又列支仪，并说明“旬支并临为上，有旬无支亦可，若止有支仪，不作此论”。因此旬仪是成课必要条件，支仪只判断课内层次。

## 编程判断

1. 由占日干支确定它所属的六甲旬。
2. 取该旬旬首的地支为旬仪。
3. 旬仪进入初传、中传或末传，即为六仪课。
4. 只有支仪而没有旬仪，不判六仪课。
5. 旬仪、支仪同时入传，只记录为上等条件，不另造课名或格名。

支仪固定对应为：子午、丑巳、寅辰、卯卯、辰寅、巳丑、午未、未申、申酉、酉戌、戌亥、亥子。

## 标准课例

《大全》举“丙辰日，寅时，未将”，三传寅、未、子。丙辰属于甲寅旬，旬仪为寅；辰日的支仪也是寅。寅发用，因此成立六仪课，并且旬仪、支仪并见。

## 象

兆多喜庆，求旺相宜。罪逢赦宥，病遇良医。投书见喜，干贵逢时。杀神回避，喜转愁眉。
