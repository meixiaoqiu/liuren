# 第二十二课：引从课

## 《六壬大全》原文与课例

出处：《六壬大全》卷八《课经集（二）·引从课》。底本见 https://www.deeporacle.ai/dianji/liuren-daquan/124-yin-cong-ke ，对照本见 https://www.xunqihuang.com/book/chapter/4b8c58050db89ac2.html 。

原文：

“凡课日辰干支前后上神发用为初末传，曰引从课。如庚辰日，干上丑昼贵人，初传寅加酉居日前，末传子加未居日后，日干得前引后从，为拱天干，又为拱贵，主官职升擢，诸事最吉。壬子日，干上辰，初传巳，末传卯，为两贵引从，主上人提携，或众贵引荐成合事，大利。甲午日，初传子居支前，末传戌居支后，前后遇引从，为拱地支，主迁修家宅，大利。丁酉日，酉为夜贵加丁干，亥为昼贵加酉支，年命在申，为贵临支干拱年命，宜告贵用事，必得两贵成就。丁巳、己巳、癸亥日伏吟，为干支拱日禄，宜占食禄事。庚午、己酉日伏吟拱夜贵。甲子日伏吟拱昼贵，为干支拱贵，宜告贵处事。此贵人出行，前者引后者从，故名引从。统涣之体，乃车马蜂拥之课也。”

象曰：“拱夹支干，仕人佳兆，官职升迁，名利荣耀，孕生英儿，婚招金玉，出行取财，干贵欢笑。如日辰上乘墓鬼，遇引从六处有冲克，凶散最吉。或干支并初中及中末拱地贵，告贵谋事亦吉。则应涣六四元吉之象也。”

课例：

- 庚辰日：“初传寅加酉居日前，末传子加未居日后”，日干得前引后从，为拱天干。
- 甲午日：“初传子居支前，末传戌居支后”，前后遇引从，为拱地支。

## 编程判断

程序采用“日辰干支前后上神发用为初末传”为成课条件，即日干寄宫或日支的前后两个地盘宫位，其上神分别成为初传、末传：

1. 拱天干（初末引从天干）：日干寄宫前一宫位上的上神发用作初传，后一宫位上的上神发用作末传。
2. 拱地支（初末引从地支）：日支前一宫位上的上神发用作初传，后一宫位上的上神发用作末传。

“前”为十二支顺时针下一宫（+1），“后”为逆时针上一宫（-1，即 +11 模 12）。日干寄宫用十干寄宫：甲寅、乙辰、丙巳、丁未、戊巳、己未、庚申、辛戌、壬亥、癸丑。

以庚辰日为例：庚寄申，申前一宫为酉、酉上神寅发用作初传；申后一宫为未、未上神子作末传，即“寅加酉、子加未”，前后夹拱申宫。

精确程序条件：

- 拱天干：`sanchuan0 === tianpan[(寄宫 + 1) % 12]` 且 `sanchuan2 === tianpan[(寄宫 + 11) % 12]`。
- 拱地支：`sanchuan0 === tianpan[(日支 + 1) % 12]` 且 `sanchuan2 === tianpan[(日支 + 11) % 12]`。

两者满足其一即成引从课；初传对应“前”一宫之上神，末传对应“后”一宫之上神。

此外，正文还列出若干夹拱变格，程序一并纳入成课条件：

3. 两贵引从：拱天干的同时，初末传又恰好分别为昼夜二贵（壬子日）。
4. 贵临干支拱年命：昼夜二贵分别加临日干寄宫与日支（方向不限），且干支前后夹拱年命（丁酉日为例）。
5. 干支拱日禄（伏吟）：日干寄宫与日支前后夹拱日禄（丁巳、己巳、癸亥日）。
6. 干支拱夜贵（伏吟）：日干寄宫与日支前后夹拱夜贵（庚午、己酉日）。
7. 干支拱昼贵（伏吟）：日干寄宫与日支前后夹拱昼贵（甲子日）。

其中“夹拱”即两个宫位分别位于目标宫位的前一宫与后一宫；“伏吟”即天盘与地盘重合（`tianpan[0] === 0`）。昼夜贵用十干起贵（甲戊庚丑未、乙己子申、丙丁亥酉、六辛午寅、壬癸巳卯），日禄用十干临官（甲寅、乙卯、丙巳、丁午、戊巳、己午、庚申、辛酉、壬亥、癸子），年命用本命（出生年支）。

当拱天干或拱地支成立、且被拱的日干寄宫或日支上神恰乘昼夜贵时，程序在对应判断中附加“又为拱贵”标注（庚辰日干上丑昼贵之例）。
