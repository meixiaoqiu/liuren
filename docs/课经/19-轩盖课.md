# 第十九课：轩盖课

## 《六壬大全》原文与课例

“凡课值胜光为用，遇太冲、神后，为轩盖课。神后子也，为紫微华盖；太冲卯也，为天驷天车；胜光午也，为天马。此三神并遇，如乘驷马轩车，高张华盖，故名轩盖。占者加官荣显，凡事吉庆，统升之体，乃士子发达之课也。”

《大全》举“甲子日卯时子将，三传卯午子，为轩盖课”。其配盘为“午青、卯朱、子后”，即初传午乘青龙、中传卯乘朱雀、末传子乘天后；《观月经》亦云“发用天马，是午胜光……中传见太冲木，本为车也。终末传神后，华盖下铺书”。

正文“三传卯午子”与配盘“午青、卯朱、子后”的顺序不一致。本实现依据“胜光为用”（初传午）的定义、配盘及所引《观月经》，采用午、卯、子顺序；正文“三传卯午子”或为三神并陈、不表先后，此点有待影印原文进一步确认，不作定论。

## 编程判断

程序将“胜光为用、太冲神后入传”落为一条固定规则：

1. 初传必须是午（胜光，天马）。
2. 中传必须是卯（太冲，天车）。
3. 末传必须是子（神后，华盖）。
4. 三项同时成立，即三传恰为午、卯、子，才判轩盖课。

月份、吉将、旺相等均不进入课名成立门槛，只作为课名之下的附加课义。

原文课义部分：“如胜光又作月内天马，太冲又作月内天车，正七月内是也。……车马作财，财自外来，更日用旺相，又为太岁月将，德神上乘贵人、龙常后合吉将，当主出入见君，拜官驿马，高车华盖，执饰喜庆，宠禄十全之荣，官爵当践公卿之位，则应初六允升大吉之象。若三传带杀，乘蛇虎死气，克年命日辰，或空亡，或卯作丧车，则刑冲从凶而动变为三交，身弱人衰，则为乘轩落马之象。主伤躬被脱，望事无成，则应上六冥升消不富之象也。”
