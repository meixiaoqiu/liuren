# 第四十四课　天祸课

## 冻结结论

课名“天祸课”，代码 `lesson.tianhuo`，属六十四课，大过卦 ䷛。本项目采用《六壬大全》详细正文的严格干支版：

```text
天祸课 = FOUR_LI_DAY
AND (
    (TODAY_STEM_ON_YESTERDAY_STEM AND TODAY_BRANCH_ON_YESTERDAY_BRANCH)
    OR
    (YESTERDAY_STEM_ON_TODAY_STEM AND YESTERDAY_BRANCH_ON_TODAY_BRANCH)
)
```

四立日按立春、立夏、立秋、立冬精确交节所在的整个公历日期判断，不以起课时刻是否已经过交节为界。“又发用”等后续文字只作凶应增强，不进入基础 matcher。

## 一、《六壬大全》正文

原文定义：

> 凡四立日占得今日干支临昨日干支，或昨日干支临今日干支，为天祸课。

正文示例：

> 正月立春甲申日，昨日为癸未，寅加癸，为天祸课。

来源：[《六壬大全·天祸课》（识典古籍直链）](https://www.shidianguji.com/book/SK1599/chapter/1k1lqkzm8oht1)、[《六壬大全》卷九课经集（中国哲学书电子化计划）](https://ctext.org/wiki.pl?chapter=319649&if=gb&remap=gb)。引文保持古籍原句，以下程序解释不混入引文。

甲寄寅，癸寄丑。“寅加癸”按十干寄宫解释为：今日甲的寄宫寅，临昨日癸的寄宫丑。严格规则下，此盘还必须同时满足今日申支临昨日未支，故正文案例属于“今日干支临昨日干支”入口。原文未提供可唯一定位的现代公历年份，本项目不为它捏造年份。

## 二、《象曰》与卦体

正文明确说“统大过之体，乃嫩草遭霜之课也”，故本课卦体为大过卦 ䷛。

《象曰》原文：

> 以新易旧，天有灾祸。咎事莫为，身宜谨守。战斗流血，造死丧偶。出行死亡，干谒空走。

来源：[《六壬大全·天祸课》（识典古籍直链）](https://www.shidianguji.com/book/SK1599/chapter/1k1lqkzm8oht1)。程序 `xiang` 字段只保存这段正文象辞；“又发用”等程序边界另放在 evidence 与本文“发用边界”一节，不混入象辞。

## 三、《图解六壬大全》整理

现代《图解六壬大全》将条件整理为：

1. 四立日占课，今日干支临昨日干支。
2. 四立日占课，昨日干支临今日干支。

该整理与本项目对《六壬大全》详细正文的严格解释一致，但现代图解仅作为辅助证据，不作为第一依据。版本信息：郭载騋原著、许颐平编著、程子和点校《图解六壬大全》第2部《吉凶占断》，华龄出版社2009年9月第1版，ISBN 978-7-80178-678-4；可由[新华书店书目信息](https://item.xhsd.com/items/1010000101170954)与[公开目录](https://www.megbook.com.hk/mall/detail.jsp?proID=2057175)核验版本及课经位置。

## 四、异说与冲突证据

《观月经》《心镜》及总诀等材料存在“四立日主要看昨日干与今日干相临”的表达或案例，可支持只看日干的传统。该冲突证据保留，不作静默删除；本项目当前不采用该口径，不设兼容模式、第二套规则、额外 OR 分支或配置项。

## 五、候选规则比较

### 候选 A：严格干支版

```text
四立日
AND
(
    今日干临昨日干 AND 今日支临昨日支
    OR
    昨日干临今日干 AND 昨日支临今日支
)
```

### 候选 B：只看干版

```text
四立日
AND
(
    今日干临昨日干
    OR
    昨日干临今日干
)
```

最终采用 A，不采用 B。理由固定为：详细正文优先；正文两次明确使用“干支”；《图解大全》也作相同拆解；总诀、口诀可能因篇幅压缩；旁证冲突予以保留，但不覆盖正文。严格结构只能在部分日干与盘面偏移中成立，命中较少是规则结果，不构成放宽条件的理由。

## 六、“临”的程序解释

十干沿用 `PanFacts::stemLodgingBranch()` 的既有寄宫表：甲寅、乙辰、丙巳、丁未、戊巳、己未、庚申、辛戌、壬亥、癸丑，不另建映射。十干寄宫的古籍依据见[《六壬大全》卷一](https://zh.wikisource.org/zh-hans/%E5%85%AD%E5%A3%AC%E5%A4%A7%E5%85%A8/1)；该链接只用于寄宫依据，不作为天祸课正文来源。

设今日干寄宫为 `todayStemLodge`、昨日干寄宫为 `yesterdayStemLodge`：

```text
今日干临昨日干 = tianpan[yesterdayStemLodge] === todayStemLodge
昨日干临今日干 = tianpan[todayStemLodge] === yesterdayStemLodge
今日支临昨日支 = tianpan[yesterdayBranch] === todayBranch
昨日支临今日支 = tianpan[todayBranch] === yesterdayBranch
```

昨日干支不重新做日期换算，而由今日合法六十甲子序号取得：`yesterdayIndex = (todayIndex + 59) % 60`，再分别对 10、12 取模。

## 七、四立日口径

`PanFacts::fourLiDay()` 使用项目 Tyme `SolarTime` 取得 index 3、9、15、21 对应的立春、立夏、立秋、立冬精确交节时间，然后只比较年、月、日。四立交节所在的整个公历日期均视为四立日，而不是只有交节后才算。

该事实独立于 `seasonalPeriod()`：季节边界仍按精确交节时刻；天祸课四立日按交节所在公历日期。现有 `seasonalPeriod()` 语义没有修改。

## 八、发用边界

正文后续“又发用”等暂按进一步凶应或增强条件处理，不进入基础 matcher。规则不检查今日干、昨日干、绝神或任何指定神是否发用，也不检查初传、凶将或克日。

## 九、生产案例与可达性

古籍甲申例无法唯一对应现代年月日，故目录使用生产代码搜索所得现代真实案例。两例均由正式 `PanCalculator` 生成，并由正式 `TianhuoRule` 命中：

- `2004-05-05 15:00:00`：立夏日，今日甲申、昨日癸未；命中“今日干支临昨日干支”。
- `2004-05-05 19:00:00`：同一立夏日；命中“昨日干支临今日干支”。

两例均不手工构造盘、不使用 mock、不注入 evidence，进入 `/kejing` 排盘页后由规则引擎实时判断。

## 十、统计

可重复脚本：`tests/Support/Statistics/TianhuoStatistics.php`。实际执行：

```bash
docker exec -w /var/www/html/liuren php85-fpm php tests/Support/Statistics/TianhuoStatistics.php 2000 2030 --compact
```

统计口径为北京项目现行时间口径，扫描 2000—2030 共 31 个完整年份、124 个四立日；每个四立日取子、丑……亥十二个代表时辰，共 1,488 盘。严格天祸命中 100 盘：入口 A“今日干支临昨日干支”50 次，入口 B“昨日干支临今日干支”50 次。去掉 `--compact` 可输出每个四立日的日期、节名、日干支以及全部命中明细。

2026 单年复核为 4 个四立日、48 盘、0 命中，说明单年零命中是可出现的结构结果，未据此放宽 matcher。

## 十一、最终程序规则

自然语言：起课日期必须是当年任一四立交节所在公历日期；并且今日干、今日支必须同向同时临昨日干、昨日支，或者昨日干、昨日支必须同向同时临今日干、今日支。两方向内部均为 AND，两方向之间为 OR；不得交叉拼接。

```text
matched = is_four_li_day
          && (
              (today_stem_on_yesterday_stem && today_branch_on_yesterday_branch)
              ||
              (yesterday_stem_on_today_stem && yesterday_branch_on_today_branch)
          )
```
