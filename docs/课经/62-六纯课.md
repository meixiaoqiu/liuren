# 62 六纯课

## 一、冻结结论

课名“六纯课”，代码 `lesson.liuchun`，卦体为革卦 `䷰`。主体 matcher 只有六阳、六阴两条独立入口，不纳入五阳、五阴或年命填实。

程序上，“四课属阳／阴，中一课发用，并中末皆阳／阴”可等价落实为：四课四上神同一阴阳，初传来自其中一课，中传、末传同一阴阳。由于初传已经是四课中的发用，不另增加一个独立阴阳位置。正文另有“四课三传俱阳／阴”的总述，两种表达在当前取传语义下相容；均不要求六支互不重复，也不要求恰好覆盖固定六支。

## 五、五阳五阴及年命填实

五阳、五阴及年命填实暂未程序化；原因是古籍扩展规则存在，但具体“填之”的机器判定语义尚未完成课例验证。它们不构成 `lesson.liuchun` 的主体入口。

## 六、课后判断

正文对六阳、六阴分别给出公私、尊卑、疾病等占断，又列六阳遇退间传、夜传昼、六阴遇昼将入夜以及出户、盈阳、励明、回明等特殊判断。这些内容均未形成可靠、独立的机器判断，本版不放入 `judgments`，统一记录在 `uncovered`。

正文“初中空，君子畏之减力，常人赖之省力末事得理”虽可部分借现有旬空事实识别初、中传逢空，但君子／常人的身份语义没有统一事实模型，本轮按最小改动整条保留为未程序化内容。

## 九、正文课例

正文保存两例资料：

- 甲午日，干上子，六阳遇退间传（戌申午）；
- 己卯日，酉加未，六阴遇昼将入夜。

### 甲午正文例

正文条件：

- 日柱：甲午。
- 干上神：子。
- 三传结构：戌、申、午（退间传 → 倒拔蛇 → 悖戾格）。
- 课体：六阳。
- 备注：正文兼述“初传戌财，引入中末鬼乡”。

证据分层：

- 六纯正文直接给出：甲午日、干上子、六阳、退间传、倒拔蛇、悖戾、初传戌财，并说其“引入中末鬼乡”。
- 间传课正文提供格名对应：戌申午为逆间传中的悖戾格。
- “倒拔蛇”是六纯正文对该退间传结构的称呼；间传正文只称“悖戾格”，故两名的对应来自两段正文合参。
- 《六壬大全》相关课表与后世转录材料均可见此盘列戌申午；本轮尚未找到一份可核验的古代或传统课表明确把该盘列为寅子戌。只能确认现代课表使用者按逐重涉害会算出寅子戌，并公开提出同一冲突；该现代讨论只作为研究线索，不能与古籍正文合并成一个结论。

#### 2024-01-31 03:00 生产计算 trace

- 日干／日支：甲（0）／午（6）；时支：寅（2）；月将：子（0）。
- 天盘（地盘子至亥）：`[戌,亥,子,丑,寅,卯,辰,巳,午,未,申,酉]`，即 `offset = -2 ≡ 10 (mod 12)`。
- 完整四课：甲上子、子上戌、午上辰、辰上寅；程序数组为 `[甲,子,子,戌,午,辰,辰,寅]`。
- 逐课生克：第一课子水生甲木（上生下）；第二课戌土克子水（上克下）；第三课午火生辰土（下生上）；第四课寅木克辰土（上克下）。没有下贼上。
- `sikeUnique` 四课均保留，原始键值为 `{1: "00", 3: "104", 5: "41", 7: "22"}`；上克下候选为第二课戌、第四课寅，候选索引 `[3,7]`；贼候选为空。
- 比用筛选：甲为阳干，戌、寅均为阳支，二者俱比，不能以比用唯一取定，进入涉害。
- 当前涉害计数：戌加子，从地盘子历至戌，遇子水与丑宫癸水，共二重；寅加辰，从地盘辰历至寅，遇辰、未、戌、丑四土及巳宫戊、未宫己，共六重。
- 因六重深于二重，当前 `PanCalculator` 走九宗门“涉害”（`jiuzongmen = 5`），取第四课寅为初传；并未进入涉害数相等后的见机／察微／缀瑕分支。中末按天盘顺传，得到寅、子、戌。
- 孟仲季位置：戌候选所临地盘子为仲，寅候选所临地盘辰为季；没有孟位候选。
- `calculationTrace.initial_transmission.method = shehai`，决策为“取涉害较深者”，深度戌=2、寅=6，最终 `sanchuan0 = 寅`；中末 trace 均为 `tianpan_shunchuan`。

#### 天地盘相容性与取用分歧

甲寄寅。干上子意味着 `tianpan[寅] = 子`，所以 `offset + 2 ≡ 0`，即 `offset ≡ 10 ≡ -2 (mod 12)`。在同一天盘上若取戌发用，则 `tianpan[戌] = 申`、`tianpan[申] = 午`，自然得到戌申午。因此干上子与退间传戌申午完全相容；`tianpan_shunchuan` 也能且应能产生这个退间传。旧文关于 offset 分别为 2、6以及结构互斥的说法错误，现已删除。

《六壬大全》涉害课正文主张逐重计算"涉地盘归本家受克深处"，并明确说"不论孟仲季……只取……最深者"；《六壬指南》又载有直接按孟、仲、季依次取用的简法，无孟则取仲。两路取法对同一甲午日会得出不同结论，显示传统内部存在取法分歧。《六壬大全》一书自身同时收录"尉山人云上克下取天盘孟仲为验存之"等异说，编纂层次并不单一；本课仅记录这两条传统取法的存在，不据其评判当前生产程序的对错。

现阶段不能据此单例宣称 `PanCalculator` 或 `ShehaiRule` 错误，也不主张逐重计数应改为其他口径。涉害深度的逐重计数口径属于核心排盘算法问题，本课不据此单例作修改；这里只记录当前生产程序实际结果。

结论：`reference_only`，`source_type = daquan`。当前盘命中六阳主体，但未复现正文指定的戌申午；冲突位于"初传取用口径"，而非天地盘或中末顺传层。本轮不改 `PanCalculator`、不改 `ShehaiRule`、不硬编码。

## 十、程序实现

`LiuchunRule` 只读取已有 `sike` 与三传 facts；先验证字段完整和初传来自四课上神，再分别判定全阳或全阴。命中分型写入 `evidence['type']`，值为 `liuyang` 或 `liuyin`。六阳、六阴不是统一意义上的增益／减损 judgment，因此 `definition()['judgments']` 与命中 evidence 中的 `judgments` 均为空。

规则已注册到 `RuleRegistry`，位于间传课及其格之后；课经目录提供两个固定、可执行的现代生产案例。

## 十三、《六壬大全》完整原文

六純課

凡四課三傳俱陽，如三傳俱陰，為六純課。如四課屬陽，中一課發用並中末皆陽，為六陽課，宜尊貴占天庭高尊事。初中空，君子畏之減力，常人賴之省力末事得理。若四課陰，中一課發用並中末俱陰，為六陰格。宜卑下占陰謀奸私事，病者死。此六者陰陽皆純，故名六純，占孕陽男陰女。統革之體，乃天淵懸隔之象也。

象曰：六陽動達，如登三天。私凶公吉，官遇升遷。六陰朦昧，似涉重淵。公凶私利，病患纏延。如甲午日幹上子，六陽遇退間傳，為倒拔蛇，名悖戾。及兼初傳戌財，引入中末鬼鄉，凡事艱辛不免功勞。或夜傳晝，事有明白。或遇五陽，以人年命定之。或六陰遇丑卯巳為出戶，卯巳未為盈陽，酉未巳為勵明，未巳卯為回明，未可以昏迷斷之，凶中有吉，則應革九五大人虎變之象。如己卯日酉加未，六陰遇晝將入夜，昏迷尤甚。將乘後合元，支幹遇盜氣，彈射發用，坐空費力不可言。問病必死，求望虛耗。或遇五陰以人年命定之。夫五陰相續，盜氣迤邐脫去，為源消根斷，本命緣不攝而死。凡占皆脫耗，則應革上六小人革面征凶之象也。
