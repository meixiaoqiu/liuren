# 第三十六课　芜淫课

## 冻结结论

课名“芜淫课”，代码 `lesson.wuyin`，属六十四课，小畜卦 `䷈`。主体采用两个独立入口：四课有克而缺一成三课，或日干、日支之上神交互克对方干支。二者为 OR，不互相增设前提。

## 《六壬大全》正式定义与象曰

本项目按《六壬大全》的严格主体保存为“三课不备而原始四课有克”，并另收“日辰上神交互相克”入口。象曰：阴阳不备，交克最嫌。利名碌碌，狱病淹淹。阴微晴久，阳少雨添。行人未至，征战愁眉。

## Path A：三课不备且有克

日干先以寄宫地支代入规范课结构：干阳 `[stemGround, sike[1]]`、干阴 `[sike[2], sike[3]]`、支阳 `[rizhi, sike[5]]`、支阴 `[sike[6], sike[7]]`。四 pair 严格去重后必须恰好为三课。克贼则独立检查原始四课位：第一课以上神对日干，其余三课按上下神五行判断；任一上克下或下贼上即成立。绝不先去重再检查克贼。

## Path B：日辰上神交互相克

干上神 `sike[1]` 克日支，同时支上神 `sike[5]` 克日干，即成立。日干日支相生、“各自相生”或其他相生条件均不进入 matcher；这些只保留为象断研究，甲子例申子相生引出的夫妻私情象义亦不程序化。

## 刚柔认课顺序与不备类型

刚日按干阳、干阴、支阳、支阴认课；柔日按支阳、支阴、干阳、干阴认课。后遇到完全相同 pair 不再计入。三个独立课中二阳一阴为阴不备，二阴一阳为阳不备；类型只用于 evidence 和判断，不增加主体条件。

## 《大全》三个正文课例

- 乙卯日午时未将，现代复现 `2019-07-17T11:00`：辰巳、巳午、卯辰、辰巳，三传辰巳午；阳不备，由 Path A 命中。
- 乙亥日巳时子将，现代复现 `2020-02-02T09:00`：辰亥、亥午、亥午、午丑，三传午丑申；阴不备，原始重复课位仍检查下贼上，由 Path A 命中。
- 甲子日卯时亥将，现代复现 `2023-03-07T05:00`：寅戌、戌午、子申、申辰，三传戌午寅；四课备，戌土克子水、申金克甲木，由 Path B 命中。

## 分源保存的宽口径

《观月经》“四课如不备，其卦号芜淫”属于只要不备即命中的宽口径；“别责亦名芜淫”亦作为传统异名保存。二者都不放宽本项目主体。《大全》以“三课有克”为芜淫，并把不备无克另归别责，正是严格区分的依据。

## 明确否决的实现

1. 只要四课不备便算芜淫。
2. 先去重成三课，再仅检查剩余三课的克贼；此错误会把 Path A 从 82/720 错减为 78/720。
3. 给 Path B 增加日干日支相生、“各自相生”或其他额外 AND 条件。

## 尚未覆盖与未来推翻条件

- “各自相生”及甲子例申子相生所引出的夫妻私情象义未作为主体条件程序化。
- 阳不备利主、阴不备利客等兵占尚未动态程序化。
- 三课不备又逢交克“占事最凶”以及凶将加重尚未程序化。
- 四课备而神将吉、兼救神，以及不备无克“不凶”的吉凶修证尚未程序化。
- 《观月经》宽口径与“别责亦名芜淫”仅分源保存。

未来只有新的、明确获准的研究结论能够推翻以上冻结边界；统计差异本身不得用于倒改规则追数。
