# 第十六课：龙德课

## 《六壬大全》原文与课例

“凡太岁、月将乘贵人发用，为龙德课。”原文随后说明，太岁与月将同在一神，又乘当日贵人作用神，是其正格；又说“如太岁乘贵人发用，传中见月将，亦是”。

《大全》举“癸巳年七月癸酉日酉时巳将”：巳为太岁，又为月将，又为癸日贵人，加酉上克下发用，三传巳、丑、酉。

## 编程判断

程序将正格与“传中见月将”合并为一条统一规则：

1. 太岁必须作初传。
2. 初传必须乘天乙贵人。
3. 月将必须出现在初、中、末三传之一。
4. 三项同时成立，才判龙德课。

若太岁与月将相同，第三项自然由初传满足；若两者不同，月将可位于中传或末传。原文没有支持“月将发用、太岁只须入传”的对称扩展，因此程序不作此扩张。

## 标准课例的昼夜贵人

《大全》卷九主张推究节气日出日入，不应把卯酉简单视为固定分界。因此酉时本身不能直接决定昼贵或夜贵：实际日落之前仍用昼贵，日落之后才用夜贵。

项目按北京经纬度计算当日日出日落，时区固定为 UTC+8。`2013-09-04 18:00` 可得《大全》所载的癸巳年、癸酉日、酉时、巳将及三传巳丑酉；北京当日日落约在 `18:41:57`，因此 `18:00` 仍用昼贵，初传巳正乘贵人，可完整复现标准课例。

## 可执行测试课例

`2013-09-04 18:00`：太岁巳与月将巳同神，巳乘贵人发用，三传巳、丑、酉。
